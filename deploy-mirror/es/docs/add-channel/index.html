Añadir Canales

Conecta OpenClaw a tus plataformas de mensajería.
OpenClaw es compatible con más de 15 canales. Añade uno o varios.

1.0 Canales Compatibles

✈️ Telegram

El más popular. Crea un bot a través de @BotFather, pega el token.

Tiempo de configuración: ~2 min Añadir Telegram →
💬 WebChat

Integrado. No requiere configuración. Accede desde el Dashboard.

Tiempo de configuración: 0 min (auto) Ya activo ✓

Próximamente en 1.1+

📱 WhatsApp 📢 Slack 🎮 Discord 🔐 Signal 📧 Google Chat 🍎 iMessage 💼 Teams 🌐 Matrix

✈️ Añadir Telegram — Paso a Paso

1

Crear Bot a través de @BotFather

Abre Telegram → busca @BotFather → /newbot → dale un nombre a tu bot → obtén el token

2

Pegar Token en el Dashboard

Dashboard → Canales → Añadir Telegram → pegar token → Conectar

123456:ABCDefGhIJKlmNoPQRsTUVwxyz...
3

DM Pairing (Seguridad de OpenClaw)

Envía cualquier mensaje a tu bot → recibe el código de emparejamiento → apruébalo en el Dashboard

⚠️ DM Pairing es la función de seguridad de OpenClaw

Los remitentes desconocidos reciben un código de emparejamiento. Apruébalo a través del Dashboard o la CLI:
agentputer pairing approve telegram <code>

✓

¡Telegram Conectado!

Tu bot @my_agent_bot ahora está vinculado a tu agente OpenClaw.
Envía cualquier mensaje para empezar a chatear. Prueba: '¿Qué puedes hacer?'

O a través de la CLI:

$ agentputer channels add telegram

? Token del bot: 123456:ABCDefGhIJKlmNoPQRsTUVwxyz

✓ Canal de Telegram añadido al Pod my-agent
