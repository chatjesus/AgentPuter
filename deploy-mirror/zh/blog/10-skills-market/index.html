AI Agent Skills 市场的真相：我们跑了数据，结果出乎意料

所有人都以为 ClawHub 是最大的 OpenClaw Skills 平台。我们调了 SimilarWeb 数据，真正的第一名流量是它的 17 倍——而它的最大用户群在中国。

OpenClaw 突破 207,000 GitHub Stars 的同时，一个平行生态也在悄悄爆发：AI Agent Skills 市场。

这些平台是开发者发布和发现 Skills 的地方——也就是那些 SKILL.md 文件，告诉 OpenClaw 怎么管理你的邮件、控制日历、监控 GitHub 仓库，甚至让 Agent 自我进化。

你大概听过 ClawHub。它是 OpenClaw 的官方 Registry，直接嵌入 CLI。你输 clawhub install skill-name，它就从那里拉。项目 README 链接到它，大多数教程都引用它。

所以它应该是最大的，对吧？

我们跑了数据。差距大到离谱。

流量真相

我们通过 SimilarWeb API 查询了 7 个 Skills 相关域名，对比了 2025年11月到 2026年1月的月访问量。结果如下：

ClawHub，OpenClaw 的官方 Registry，月访问量 5.6 万，排第三。 而 SkillsMP——一个西方 OpenClaw 社区几乎没人提到过的平台——月访问量 95.8 万，接近 100 万。是 ClawHub 的 17 倍，同时也是它三个月前自己流量的 18 倍——这是两个不同维度的数字，别混了。

这个品类六个月前几乎不存在。到 2026 年 1 月，Skills 发现平台的合并月流量已经超过 160 万次访问。整个市场是从零开始，用半年时间长出来的。

谁在赢？为什么？

第一名：SkillsMP —— 西方世界不知道的流量霸主

SkillsMP 在英语 OpenClaw 社区几乎没有存在感。Discord 里没人提它，官方文档不链接它。但它每月接近 100 万访客。

数据告诉你原因：SkillsMP 35.2% 的流量来自中国，是最大的单一国家用户群。加上台湾（9.7%）、新加坡（4.8%）、香港（3.9%）、越南（3.7%），亚太地区占总访问量的 50% 以上。这是一个”中国互联网用户主导”的平台——在一个美国人创建的西方开源项目的工具生态里。

流量结构异常健康：

流量来源访问量占比
直接访问501,68552.4%
自然搜索239,72225.0%
社交媒体163,80717.1%
外链引荐40,9284.3%
付费广告9,7231.0%

SEO 贡献 25%，社交贡献 17%——这是成熟内容策略的结果，不是运气。跳出率（39%）和平均访问时长（4.5 分钟、4.9 页/次）都说明用户在认真浏览，不是看一眼就走。

我们的判断： SkillsMP 很可能由中国团队运营，或有强大的中文内容分发能力。平台聚合了超过 239,000 个 Skills，覆盖 Claude Code、Cursor Rules、OpenAI Codex、OpenClaw 等多个 AI 工具生态，而不只是 OpenClaw。定位宽泛，而非深耕。

第二名：agentskills.io —— 有品牌背书，但 SEO 是空白

agentskills.io 实际上在 2025 年 12 月才开始有流量，一个月后就达到 55.8 万月访问。这个增速很罕见。

原因是 Anthropic。这个站是 Anthropic 定义的”Agent Skills”开放格式的官方主页——Claude Code、Cursor、OpenAI Codex 和 OpenClaw 共用的 SKILL.md 标准。靠着 Anthropic 的影响力，它天然获得了品牌认知和直接流量。

数字验证了这一点：agentskills.io 的 70.2% 流量是直接访问——用户直接输网址或点书签。这是品牌力量的信号。

但看看缺了什么：

流量来源访问量占比
直接访问392,01170.2%
社交媒体64,98711.6%
外链引荐51,0389.1%
自然搜索35,6266.4%

只有 6.4% 来自搜索。对一个月访问量 55 万的站来说，这是一个巨大的结构性弱点。一旦热度退却，直接流量会趋于正常——而几乎没有 SEO 基础来接住这个下落。

参与度指标印证了这一点：平均 1.8 分钟会话时长，62.4% 跳出率，2.2 页/次。用户来了，扫一眼技能列表或文档页就离开。没有留下来的理由。

我们的判断： agentskills.io 在吃 Anthropic 热度的红利。增长很快，但很脆弱。如果不在内容深度和 SEO 上投入，增长会很快遇到天花板。

第三名：clawhub.ai —— 流量小，但用户密度最高

ClawHub（clawhub.ai）到 2026 年 1 月才出现在 SimilarWeb 数据里。月访问量 5.6 万，虽然超过了持续下滑的 playbooks.com（4.3 万），但跟领先者没法比。

但看看这些用户在做什么：

指标clawhub.aiagentskills.ioskillsmp.com
平均访问时长274秒（4.6分钟）108秒270秒
跳出率41.3% 🟢62.4% 🔴39.0% 🟢
每次访问页数8.0页 🌟2.2页4.9页

每次访问 8 页。近 5 分钟的会话时长。ClawHub 上的用户是在工作——翻看技能列表、读 SKILL.md 文件、对比不同版本。这些是真正在用 OpenClaw 构建东西的开发者。

地理分布也很能说明问题：ClawHub 58.1% 的流量来自美国，而 SkillsMP 是中国第一（35.2%）。ClawHub 是英语开发者聚集的地方——重度用户、高质量受众。

我们的判断： ClawHub 拥有整个生态里质量最高的用户。但几乎没有社交流量（759次！），没有 SEO 布局，没有付费推广——它对 OpenClaw 核心社区之外的人几乎是隐形的。

没有人占据的空白

一段话说清竞争格局：SkillsMP 有流量但没有 OpenClaw 深度。agentskills.io 有品牌但内容不耐用。ClawHub 有对的用户但没有触达能力。而整个可计量市场——以 SkillsMP 11 月的流量为基准——三个月内增长了约 30 倍，总月访问量达到 160 万，还在加速。

没有人填的空白是：以内容为核心、专注 OpenClaw、建立持久 SEO、同时服务中英文用户，并创造复访理由（周榜、每日教程、月报）的平台。

数据揭示的三个具体机会：

机会一：OpenClaw 专项 SEO 几乎是空白地带。 SkillsMP 的 25% 搜索流量来自宽泛的 AI 工具查询。agentskills.io 搜索只占 6.4%。针对”openclaw email skill tutorial”、“best openclaw skills 2026”、“openclaw gog google workspace setup”这类精准词，竞争格局几乎是空的。一个专注的内容团队可以相对轻松地占据这些词。

机会二：中文 OpenClaw 内容几乎不存在。 SkillsMP 靠通用 AI 内容统治中文流量。但专门针对 OpenClaw 的中文内容——如何在国内 VPS 部署、哪些 Skills 支持 DeepSeek / Kimi 等国产模型、如何配合企业微信/钉钉工作流——几乎什么都没有。中国用户占所有测量平台 20–35% 的流量。

机会三：有粘性的内容能创造复访，但没人做。 ClawHub 之所以能实现 8 页/次是因为有一个实时 Registry 供用户浏览。但没有周榜、没有”本周精选 Skill”、没有编辑层次。那些愿意为精选内容回来的用户，没有任何理由回来。

这对 OpenClaw 用户意味着什么

如果你只是想找好的 Skills 用： 不要只靠 ClawHub 的浏览界面。官方 Registry 有真货——3,286 个 Skills，有真实下载数据和安全评分——但发现体验很薄。在专属内容平台成熟之前，最好的资源是 OpenClaw Top 100 精选榜单，它用安全评分加权而不只看人气。

安全注意： 2026年2月的 ClawHavoc 事件——Koi Security 初审在 2,857 个 Skills 中标记了 341 个恶意的，后续全面调查又追溯出 1,184 个、涉及 12 个发布者账号——提醒我们，下载量不等于安全。安全评分系统（A-D 级）是正确的过滤器。A 级目前只有两个（nano-pdf 和 video-frames），B 级是 Top 100 的主力，D 级应该先在沙箱测试再装。

主导趋势是：Agent 在自我进化、自主操作，而不只是回答你的问题。“打开聊天框问它事情”这个早期用例，正在被”持续运行、主动学习、不需要你提示就能干活”的系统取代。

更大的图景

AI Agent Skills 市场现在的状态，就像 npm 在 2011 年、App Store 在 2009 年——混乱、高速增长、还没有一个真正的统治者。从几乎零访问量到 160 万月访问量，这个品类用了不到六个月。OpenClaw 的 207,000 GitHub Stars 代表着一大批还没发现 Skills 生态的潜在用户。

最终赢得这个市场的平台，是那个能帮这 207,000 人回答一个问题的平台：

“我装好了 OpenClaw，现在应该先装哪些 Skills？为什么？”

答案不是一个列表。是每周的榜单，每天的教程，每月的生态变化摘要。是有足够深度让用户停留 8 分钟而不是 1.8 分钟的内容。

这个平台现在还不存在。窗口还开着。

数据方法说明：所有流量数据均于 2026年2月18日通过 SimilarWeb API 直接查询。月访问量、流量来源分布和参与度指标（跳出率、访问时长、每次访问页数）均为 SimilarWeb 基于面板数据的估算值。地区分布为各国家占总流量的百分比。所有数据均为桌面端流量。
