Skills & ClawHub

O OpenClaw inclui mais de 50 Skills integradas e mais de 565 Skills da comunidade via ClawHub.
O AgentPuter pré-carrega Skills populares e permite que você as gerencie a partir do Dashboard.

$ agentputer skills list

Integradas: 50 Skills carregadas

ClawHub: 565+ disponíveis

Execute: agentputer skills install <nome>

O que você vai construir:

seu-terminal

$ agentputer create my-agent

✓ Pod pronto (OpenClaw v2026.2.6 pré-instalado)

✓ Gateway em execução (ws://pod-abc123:18789)

$ agentputer channels add telegram

✓ Bot @my_agent_bot conectado

$ agentputer status

✓ Pod: em execução | OpenClaw: v2026.2.6 | Canais: 1

✓ Skills: 12 ativas | ClawHub: conectado

CONFIGURAR

Configurações do Pod

Um Pod é a sua instância de servidor do AgentPuter — um contêiner sempre ativo executando o OpenClaw. Configure região, recursos e armazenamento a partir do Dashboard.

$ agentputer pod info my-agent

Região: us-east-1

CPU: 2 vCPU | RAM: 2 GB

Armazenamento: 40 GB SSD (2.1 GB usados)

OpenClaw: v2026.2.6 (atualização automática: ligada)

Status: em execução (ativo há: 14d 6h)

Ambiente & Segredos

Configure as chaves de API do seu modelo de IA e outros segredos. O AgentPuter os armazena criptografados e os injeta na sua instância do OpenClaw — sem necessidade de acessar via SSH e editar arquivos JSON.

$ agentputer config set agent.model=anthropic/claude-opus-4-6

✓ Modelo atualizado

$ agentputer secrets set ANTHROPIC_API_KEY=sk-ant-...

✓ Segredo armazenado (criptografado)

Modelo recomendado: Anthropic Claude Opus 4.6 (melhor para contexto longo + anti-injeção). Você precisa da sua própria chave de API ou de uma assinatura Anthropic Pro (US$ 20/mês).

Acesso SSH

Usuários avançados podem acessar seus Pods diretamente via SSH para configuração avançada, depuração ou para executar comandos do CLI do OpenClaw.

$ agentputer ssh my-agent

Conectando a pod-abc123...

root@pod-abc123:~#

# Agora você pode executar comandos do openclaw diretamente:

$ openclaw doctor

✓ Todas as verificações passaram

ENTENDA

Segurança & Privacidade

O AgentPuter isola cada Pod em seu próprio contêiner. Seus dados permanecem no seu Pod.
O OpenClaw fornece DM Pairing para controlar quem pode enviar mensagens para o seu agente.

Isolamento de Pod

Contêiner dedicado por usuário. Sem recursos compartilhados.

DM Pairing

Autenticação nativa do OpenClaw. Remetentes desconhecidos devem ser aprovados.

Segredos Criptografados

Chaves de API armazenadas com criptografia, nunca expostas aos modelos.

Modo Sandbox

O Sandbox do OpenClaw limita o que as Skills podem acessar.

Solução de Problemas

Problemas comuns e como corrigi-los.

O bot não está respondendo?

Verifique o status do Pod: agentputer status. Confirme se a sua chave de API do modelo está definida e é válida.

O código do DM Pairing não está chegando?

Certifique-se de que o Token do bot está correto. Tente: openclaw doctor via SSH.

O Pod não inicia?

Verifique os logs: agentputer logs my-agent. Entre em contato com o suporte se o problema persistir.

Custo & Uso

Seus custos vêm de duas fontes:

① AgentPuter (Infraestrutura)

Taxa de hospedagem do Pod. Cobre computação, armazenamento, rede, atualizações automáticas e acesso ao Dashboard.

② API do Modelo (Sua assinatura)

Uso do modelo de IA. Você usa sua própria chave de API (ex: Anthropic Pro US$ 20/mês).
O AgentPuter fornece um painel de monitoramento de custos para que você sempre saiba seus gastos.

$ agentputer usage my-agent

Este mês: 1.247 mensagens | ~US$ 8,40 de custo de API

Limite de orçamento: US$ 50/mês | Usado: 16,8%
