Skills & ClawHub

OpenClaw enthält über 50 integrierte Skills und mehr als 565 Community-Skills über ClawHub.
AgentPuter lädt beliebte Skills vor und ermöglicht Ihnen, sie über das Dashboard zu verwalten.

$ agentputer skills list

Integriert: 50 Skills geladen

ClawHub: 565+ verfügbar

Ausführen: agentputer skills install <name>

Was Sie erstellen werden:

dein-terminal

$ agentputer create my-agent

✓ Pod bereit (OpenClaw v2026.2.6 vorinstalliert)

✓ Gateway läuft (ws://pod-abc123:18789)

$ agentputer channels add telegram

✓ Bot @my_agent_bot verbunden

$ agentputer status

✓ Pod: läuft | OpenClaw: v2026.2.6 | Kanäle: 1

✓ Skills: 12 aktiv | ClawHub: verbunden

🔄

KONFIGURIEREN

Pod-Einstellungen

Ein Pod ist Ihre AgentPuter-Serverinstanz – ein ständig aktiver Container, der OpenClaw ausführt. Konfigurieren Sie Region, Ressourcen und Speicher über das Dashboard.

$ agentputer pod info my-agent

Region: us-east-1

CPU: 2 vCPU | RAM: 2 GB

Speicher: 40 GB SSD (2,1 GB genutzt)

OpenClaw: v2026.2.6 (Auto-Update: an)

Status: läuft (Uptime: 14T 6h)

Umgebung & Secrets

Konfigurieren Sie Ihre KI-Modell-API-Schlüssel und andere Secrets. AgentPuter speichert sie verschlüsselt und fügt sie in Ihre OpenClaw-Instanz ein – kein SSH-Login und Bearbeiten von JSON-Dateien erforderlich.

$ agentputer config set agent.model=anthropic/claude-opus-4-6

✓ Modell aktualisiert

$ agentputer secrets set ANTHROPIC_API_KEY=sk-ant-...

✓ Secret gespeichert (verschlüsselt)

Empfohlenes Modell: Anthropic Claude Opus 4.6 (bester Long-Context + Anti-Injection). Sie benötigen Ihren eigenen API-Schlüssel oder ein Anthropic Pro-Abonnement (20 $/Monat).

SSH-Zugriff

Power-User können sich für erweiterte Konfiguration, Debugging oder die Ausführung von OpenClaw-CLI-Befehlen direkt per SSH in ihren Pod einloggen.

$ agentputer ssh my-agent

Verbinde mit pod-abc123...

root@pod-abc123:~#

# Jetzt können Sie openclaw-Befehle direkt ausführen:

$ openclaw doctor

✓ Alle Prüfungen bestanden

VERSTEHEN

Sicherheit & Datenschutz

AgentPuter isoliert jeden Pod in einem eigenen Container. Ihre Daten bleiben in Ihrem Pod.
OpenClaw bietet DM Pairing, um zu steuern, wer Ihrem Agenten Nachrichten senden kann.

Pod-Isolierung

Dedizierter Container pro Benutzer. Keine geteilten Ressourcen.

DM Pairing

Integrierte Authentifizierung von OpenClaw. Unbekannte Absender müssen genehmigt werden.

Verschlüsselte Secrets

API-Schlüssel werden verschlüsselt gespeichert und niemals Modellen preisgegeben.

Sandbox-Modus

Die OpenClaw Sandbox schränkt den Zugriff von Skills ein.

Fehlerbehebung

Häufige Probleme und deren Lösungen.

Bot antwortet nicht?

Überprüfen Sie den Pod-Status: agentputer status. Stellen Sie sicher, dass Ihr Modell-API-Schlüssel gesetzt und gültig ist.

DM Pairing-Code kommt nicht an?

Stellen Sie sicher, dass der Bot-Token korrekt ist. Versuchen Sie: openclaw doctor via SSH.

Pod startet nicht?

Überprüfen Sie die Logs: agentputer logs my-agent. Kontaktieren Sie den Support, wenn das Problem weiterhin besteht.

Kosten & Nutzung

Ihre Kosten setzen sich aus zwei Quellen zusammen:

① AgentPuter (Infrastruktur)

Pod-Hosting-Gebühr. Deckt Rechenleistung, Speicher, Netzwerk, automatische Updates und den Zugriff auf das Dashboard ab.

② Modell-API (Ihr Abonnement)

Nutzung des KI-Modells. Sie verwenden Ihren eigenen API-Schlüssel (z. B. Anthropic Pro für 20 $/Monat).
AgentPuter bietet ein Dashboard zur Kostenüberwachung, damit Sie Ihre Ausgaben immer im Blick haben.

$ agentputer usage my-agent

Diesen Monat: 1.247 Nachrichten | ~8,40 $ API-Kosten

Budgetlimit: 50 $/Monat | Genutzt: 16,8 %
