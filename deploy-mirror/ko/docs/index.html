Skills & ClawHub

OpenClaw는 50개 이상의 내장 Skills와 ClawHub를 통한 565개 이상의 커뮤니티 Skills를 포함합니다.
AgentPuter는 인기 있는 Skills를 미리 로드하며, Dashboard에서 관리할 수 있도록 지원합니다.

$ agentputer skills list

내장: 50개 Skills 로드됨

ClawHub: 565개 이상 사용 가능

실행: agentputer skills install <name>

무엇을 만들게 될까요:

your-terminal

$ agentputer create my-agent

✓ Pod 준비 완료 (OpenClaw v2026.2.6 사전 설치됨)

✓ 게이트웨이 실행 중 (ws://pod-abc123:18789)

$ agentputer channels add telegram

✓ 봇 @my_agent_bot 연결됨

$ agentputer status

✓ Pod: 실행 중 | OpenClaw: v2026.2.6 | 채널: 1

✓ Skills: 12개 활성 | ClawHub: 연결됨

🔄

자체 호스팅 OpenClaw에서 마이그레이션하시나요?

마이그레이션 가이드는 곧 제공될 예정입니다. 그동안은 빠른 시작 가이드를 이용해 주세요.

구성

Pod 설정

Pod는 여러분의 AgentPuter 서버 인스턴스입니다 — OpenClaw를 실행하는 상시 가동 컨테이너입니다. Dashboard에서 리전, 리소스, 스토리지를 구성하세요.

$ agentputer pod info my-agent

리전: us-east-1

CPU: 2 vCPU | RAM: 2 GB

스토리지: 40 GB SSD (2.1 GB 사용됨)

OpenClaw: v2026.2.6 (자동 업데이트: 켜짐)

상태: 실행 중 (가동 시간: 14일 6시간)

환경 및 시크릿

AI 모델 API 키와 다른 시크릿들을 구성하세요. AgentPuter는 이를 암호화하여 저장하고 OpenClaw 인스턴스에 주입합니다 — SSH로 접속하여 JSON 파일을 편집할 필요가 없습니다.

$ agentputer config set agent.model=anthropic/claude-opus-4-6

✓ 모델 업데이트됨

$ agentputer secrets set ANTHROPIC_API_KEY=sk-ant-...

✓ 시크릿 저장됨 (암호화)

추천 모델: Anthropic Claude Opus 4.6 (긴 컨텍스트 처리 및 인젝션 방지에 최적). 자체 API 키 또는 Anthropic Pro 구독($20/월)이 필요합니다.

SSH 접근

파워 유저는 고급 구성, 디버깅 또는 OpenClaw CLI 명령어 실행을 위해 Pod에 직접 SSH로 접속할 수 있습니다.

$ agentputer ssh my-agent

pod-abc123에 연결 중...

root@pod-abc123:~#

# 이제 openclaw 명령어를 직접 실행할 수 있습니다:

$ openclaw doctor

✓ 모든 검사 통과

이해

보안 및 개인정보 보호

AgentPuter는 각 Pod를 자체 컨테이너에 격리합니다. 여러분의 데이터는 Pod 내에 안전하게 보관됩니다.
OpenClaw는 DM Pairing 기능을 제공하여 누가 에이전트에게 메시지를 보낼 수 있는지 제어합니다.

Pod 격리

사용자별 전용 컨테이너. 리소스 공유 없음.

DM Pairing

OpenClaw 내장 인증. 알 수 없는 발신자는 승인이 필요합니다.

암호화된 시크릿

API 키는 암호화되어 저장되며 모델에 노출되지 않습니다.

샌드박스 모드

OpenClaw 샌드박스는 Skills가 접근할 수 있는 범위를 제한합니다.

문제 해결

일반적인 문제와 해결 방법입니다.

봇이 응답하지 않나요?

Pod 상태를 확인하세요: agentputer status. 모델 API 키가 설정되어 있고 유효한지 확인하세요.

DM Pairing 코드가 도착하지 않나요?

봇 Token이 올바른지 확인하세요. SSH를 통해 openclaw doctor를 시도해 보세요.

Pod가 시작되지 않나요?

로그를 확인하세요: agentputer logs my-agent. 문제가 지속되면 지원팀에 문의하세요.

비용 및 사용량

비용은 두 가지 출처에서 발생합니다:

① AgentPuter (인프라)

Pod 호스팅 비용. 컴퓨팅, 스토리지, 네트워킹, 자동 업데이트 및 Dashboard 접근을 포함합니다.

② 모델 API (사용자 구독)

AI 모델 사용량. 사용자 소유의 API 키(예: Anthropic Pro $20/월)를 사용합니다.
AgentPuter는 비용 모니터링 대시보드를 제공하여 항상 지출을 파악할 수 있도록 돕습니다.

$ agentputer usage my-agent

이번 달: 1,247개 메시지 | ~$8.40 API 비용

예산 한도: $50/월 | 사용량: 16.8%
