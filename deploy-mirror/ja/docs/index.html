Skills & ClawHub

OpenClawには50以上の組み込みSkillsと、ClawHub経由で565以上のコミュニティSkillsが含まれています。
AgentPuterは人気のSkillsをプリロードし、Dashboardから管理できます。

$ agentputer skills list

組み込み: 50個のSkillsがロード済み

ClawHub: 565+個が利用可能

実行: agentputer skills install <name>

作成するもの:

your-terminal

$ agentputer create my-agent

✓ Pod準備完了 (OpenClaw v2026.2.6 プリインストール済み)

✓ ゲートウェイ実行中 (ws://pod-abc123:18789)

$ agentputer channels add telegram

✓ Bot @my_agent_bot が接続されました

$ agentputer status

✓ Pod: 実行中 | OpenClaw: v2026.2.6 | チャンネル: 1

✓ Skills: 12個がアクティブ | ClawHub: 接続済み

CONFIGURE

Pod 設定

PodはあなたのAgentPuterサーバーインスタンスです — OpenClawを実行する常時稼働のコンテナです。 リージョン、リソース、ストレージはDashboardから設定します。

$ agentputer pod info my-agent

リージョン: us-east-1

CPU: 2 vCPU | RAM: 2 GB

ストレージ: 40 GB SSD (2.1 GB 使用済み)

OpenClaw: v2026.2.6 (自動更新: on)

ステータス: 実行中 (稼働時間: 14日 6時間)

環境とシークレット

AIモデルのAPIキーやその他のシークレットを設定します。AgentPuterはそれらを暗号化して保存し、 OpenClawインスタンスに注入します — SSHでログインしてJSONファイルを編集する必要はありません。

$ agentputer config set agent.model=anthropic/claude-opus-4-6

✓ モデルが更新されました

$ agentputer secrets set ANTHROPIC_API_KEY=sk-ant-...

✓ シークレットが保存されました (暗号化済み)

推奨モデル: Anthropic Claude Opus 4.6 (最高の長文コンテキスト + アンチインジェクション)。 ご自身のAPIキーまたはAnthropic Proのサブスクリプション($20/月)が必要です。

SSH アクセス

パワーユーザーはPodに直接SSH接続して、高度な設定、 デバッグ、またはOpenClaw CLIコマンドの実行ができます。

$ agentputer ssh my-agent

pod-abc123に接続中...

root@pod-abc123:~#

# これでopenclawコマンドを直接実行できます:

$ openclaw doctor

✓ すべてのチェックに合格しました

UNDERSTAND

セキュリティとプライバシー

AgentPuterは各Podを独自のコンテナに分離します。あなたのデータはあなたのPod内に留まります。
OpenClawは、誰がエージェントにメッセージを送れるかを制御するためのDM Pairingを提供します。

Podの分離

ユーザーごとに専用コンテナ。共有リソースなし。

DM Pairing

OpenClawの組み込み認証。未知の送信者は承認が必要です。

暗号化されたシークレット

APIキーは暗号化して保存され、モデルに公開されることはありません。

サンドボックスモード

OpenClaw SandboxはSkillsがアクセスできるものを制限します。

トラブルシューティング

よくある問題とその解決方法。

ボットが応答しませんか？

Podのステータスを確認してください: agentputer status。 モデルのAPIキーが設定され、有効であることを確認してください。

DM Pairingコードが届きませんか？

ボットのTokenが正しいことを確認してください。SSH経由で openclaw doctor を試してください。

Podが起動しませんか？

ログを確認してください: agentputer logs my-agent。 問題が解決しない場合は、サポートにお問い合わせください。

コストと使用量

コストは2つの要素から構成されます:

① AgentPuter (インフラストラクチャ)

Podのホスティング料金。コンピューティング、ストレージ、ネットワーク、自動更新、Dashboardへのアクセスが含まれます。

② モデルAPI (ご自身のサブスクリプション)

AIモデルの使用量。ご自身のAPIキーをご用意ください (例: Anthropic Pro $20/月)。
AgentPuterはコスト監視ダッシュボードを提供し、いつでも支出を把握できます。

$ agentputer usage my-agent

今月: 1,247メッセージ | ~$8.40 APIコスト

予算上限: $50/月 | 使用率: 16.8%
