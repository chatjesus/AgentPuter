// 차이점
✗ AGENTPUTER가 없을 때

✗ 노트북을 닫으면 → 에이전트 즉시 종료

✗ OAuth 토큰 만료 → 매 세션마다 다시 로그인

✗ 30-50개 메시지 후 컨텍스트 손실

✗ 2시간 만에 200달러 소진 — 비용 보호 장치 없음

✗ 780개 이상의 노출된 인스턴스 — 인증 없음

✗ 어떤 이메일이든 에이전트에 프롬프트 인젝션 가능

✗ 매주 3.7시간씩 AI에게 컨텍스트 재설명

✓ AGENTPUTER를 사용할 때

✓ 24/7 클라우드 Pod → 에이전트가 절대 멈추지 않음

✓ 인증 프록시 → Token 자동 무한 갱신

✓ 영구적인 작업 공간 → 즉시 작업 재개

✓ 세션별 예산 한도 → 예상치 못한 요금 청구 없음

✓ 격리된 VPS → 데이터는 온전히 당신의 것

✓ 정제된 I/O → 프롬프트 인젝션 완화

✓ 전체 감사 추적 → 모든 활동 기록

"에이전트는 종종 env vars, 파일, CLI, 브라우저, API 키 등 광범위한 로컬 접근이 필요합니다. 이 때문에 '로컬 머신은 안전하다'는 일반적인 가정이 흔들리게 되죠."

하나의 플랫폼, 다섯 가지 역할

AgentPuter는 단순한 기능 목록이 아닙니다.
AI 워크플로우에서 다섯 가지 핵심적인 역할을 수행합니다.

[🔒]

프라이버시 프록시

// 당신의 데이터는 당신의 통제하에 있습니다

ChatGPT에 은행 계좌 정보를 붙여넣지는 않을 겁니다. AgentPuter는 당신과 LLM 사이의 방화벽 역할을 합니다. 데이터를 정화하고, 권한을 관리하며, 데이터 소유권이 당신에게 있도록 보장합니다.

agentputer — 프라이버시 프록시

$ agentputer privacy status

 

데이터 흐름: 사용자 → AgentPuter → [정화됨] → LLM

자격 증명: 저장 시 암호화 (AES-256)

API 키: 관리되며, 모델에 노출되지 않음

PII 탐지: 활성, 자동 수정 활성화

✓ 당신의 데이터는 당신의 것입니다

[🧠]

컨텍스트 매니저

// 절대 잊지 않는 메모리

LLM은 기억 상실증에 걸리기 쉽습니다. AgentPuter는 에이전트에게 장기 기억을 제공합니다. 워크플로우, 환경설정, 파일 히스토리를 구조화된 컨텍스트로 변환하여 정확도를 높이면서 토큰을 절약합니다.

agentputer — 컨텍스트 매니저

$ agentputer context show

 

장기 기억: 847개 항목

환경설정: 23개 규칙 로드됨

파일 히스토리: 156개 파일 추적 중

토큰 절약: ~62% (스마트 컨텍스트)

마지막 동기화: 2분 전

✓ 중단했던 부분부터 바로 시작

[🔌]

통합 인터페이스

// 에이전트에게 필요한 모든 것을 위한 단 하나의 API

문서, 이메일, 웹, 코드 등 모든 기능이 표준화된 'Tool'로 래핑됩니다. 에이전트는 각 API를 배울 필요 없이, 마치 사람이 마우스를 사용하듯 자연스럽게 기능을 호출합니다.

agentputer — 통합 인터페이스

$ agentputer tools list

 

├── 문서 (읽기, 쓰기, 변환)

├── 이메일 (보내기, 읽기, 검색)

├── 웹 (브라우징, 스크래핑, API)

├── 캘린더 (이벤트, 리마인더)

├── 코드 (실행, 테스트, deploy)

├── 파일 (CRUD, 정리)

└── 사용자 정의 (Skills 마켓플레이스)

✓ 7개 핵심 도구 + 무제한 Skills

영구 워크스페이스

// 당신의 에이전트 전용 데스크톱

에이전트는 자체 파일 시스템, 코드 저장소, 리서치 노트를 가집니다. 작업하던 내용은 저장되고, 다음 세션은 이전 세션이 끝난 지점에서 정확히 다시 시작됩니다.

책임 추적 로그

// 모든 활동을 기록하고 검토 가능

사무 업무

"지난주 판매 데이터를 취합해서 보고서를 작성하고 매니저에게 이메일로 보내줘." 에이전트가 데이터를 가져와 분석, 형식 지정 후 전송까지 완료합니다. 당신은 검토만 하면 됩니다.

🔬

리서치

"2025년 전기차 시장 트렌드를 리서치해줘." 검색, 자료 읽기, 핵심 포인트 추출 후 노트북을 생성합니다. 후속 작업을 위해 저장됩니다.

💻

개발

"우리 제품 랜딩 페이지를 만들어줘." 독립된 개발 환경에서 코드를 작성하고, 테스트를 실행하며, 버그를 수정하고, deploy합니다. 막히면 당신에게 질문합니다.

🎨

크리에이티브

"1분기 소셜 미디어 캠페인을 기획해줘." 독립된 캔버스와 에셋을 활용해 초안을 생성하고, 반복 작업을 거쳐 버전을 저장합니다. 당신은 지시만 내리면 됩니다.
