まず最初に：OpenClawとは？（30秒版）

OpenClawは、ブラウザでアクセスするような単なるチャットボットではありません。バックグラウンドで24時間365日稼働し、あなたが普段使っているメッセージングアプリ — WhatsApp、Telegram、Slack、Discord、Google Chat、Signal、iMessage (BlueBubbles経由)、Microsoft Teams、WebChat、Matrixなど — を通じてあなたと対話するパーソナルAIアシスタントです。対応チャネルは12種類以上あり、現在も増え続けています。

ChatGPTとの違い：

  • 永続的な記憶。 OpenClawにはSOUL.mdというファイルがあり、あなたにとってそれが何者であるか — あなたの名前、好み、仕事のスタイル、タイムゾーンなどを定義します。セッションを越えて記憶を保持します。
  • 現実世界でのアクション。 メールの読み取り、カレンダーの管理、ファイルの操作、スマートホームデバイスの制御、調査、返信の下書き作成などを — 自律的に行います。
  • 音声とキャンバス。 Voice WakeとTalk Mode（ElevenLabs搭載）により、ハンズフリーで対話できます。Live Canvas (A2UI) は、視覚的なワークスペースを提供します。
  • ローカルファースト。 あなたのデータはあなたのマシン上に留まります。あなたの会話がトレーニングに使用されることはありません。あなたが選択しない限り、第三者のクラウドは使用されません。

実行に必要なもの:

  • **Node.js 22+**が動作するマシン (macOS、Linux、またはWSL2経由のWindows)
  • AIモデルのサブスクリプション: Anthropic APIキーまたはClaude Pro/Max OAuth (プロジェクト作成者が強く推奨)、またはOpenAI / Google Gemini
  • 公式の推奨: Anthropic Pro/Max + Opus 4.6 — 対応モデルの中で最高の長文コンテキスト性能と最も強力なプロンプトインジェクション耐性

パスA: Mac Mini — ローカルサーバー

対象者: Mac Miniを所有している（または欲しいと思っている）方。100%ローカルでの管理を望み、データ主権を重視し、iMessage連携や音声起動（Voice Wake）を利用したい方。

ハードウェア

Mac Mini M4のベースモデル（599ドル）で十分すぎるほどです。スペックは16GBのユニファイドメモリ、256GBのストレージです。アイドル時の消費電力は5～10Wで、年間の電気代は約15ドル程度。静音で常時稼働し、BlueBubblesを介してiMessageをネイティブにサポートします。これは、どのクラウドデプロイメントにも真似できない利点です。

整備済み製品を購入する場合、16GBメモリ搭載のM2モデルでも問題なく動作します。8GBモデルは避けてください。高負荷時にOpenClawとモデルのコンテキストウィンドウがスワップを発生させ、SSD上でのスワップはドライブの寿命を縮める原因となります。

前提条件

開始する前に、以下のものが揃っていることを確認してください:

  • macOS 13 (Ventura) 以降
  • Homebrewがインストール済みであること (/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)")
  • Node.js 22以降 (brew install node@22でインストール後、node --versionで確認)
  • Anthropic APIキー、またはOAuthログイン用のClaude Pro（月額20ドル）/ Max（月額100ドル）のサブスクリプション
  • Telegramアカウント（最初に始めるチャネルとして最も簡単です）

インストール手順

ステップ1: OpenClawをグローバルにインストールする

npm install -g openclaw@latest

pnpm (pnpm add -g openclaw@latest) や bun も使用できます。これら3つすべてが公式にサポートされています。

以下のような内容で終わる出力が表示されるはずです:

12秒で1個のパッケージを追加しました


インストールの確認:

```bash
openclaw --version

期待される出力: 2026.2.17 (または最新のリリース番号)。

ステップ2: オンボーディングウィザードの実行

openclaw onboard --install-daemon

ウィザードが対話形式ですべてを案内します:

  1. モデルを選択します。 Anthropic Claude (推奨) を選択してください。Claude Pro/Max のサブスクリプションをお持ちの場合は、OAuth ログインを選択してください — API キーの管理は不要です。
  2. API キーを入力するか、OAuth で認証します。
  3. メッセージングチャンネルを選択します。 Telegram が最も簡単に始められます。ウィザードの指示に従い、Telegram で @BotFather にメッセージを送り、/newbot で新しいボットを作成し、トークンを貼り付けてください。
  4. バックグラウンドデーモンをインストールします。 macOS では、これにより launchd サービスが作成され、OpenClaw は再起動後も、ターミナルが閉じられても実行され続けます。

プロセス全体は約5分で完了します。

ステップ3: インストールの検証

openclaw doctor

これは公式の診断ツールです。Node.js のバージョン、Gateway との接続性、チャンネル設定、モデルへのアクセス、デーモンのステータスをチェックします。すべてのチェック項目に緑色のチェックマークが表示されるはずです。黄色や赤色の項目がある場合、doctor が修正すべき点を正確に教えてくれます。

ステップ4: 最初のデバイスをペアリングする

Telegramを開き、新しいボットに何かメッセージを送ってください。ボットがペアリングコードを返信します — これはOpenClawのデフォルトのセキュリティメカニズムです。知らない送信者にはコードが送られ、あなたが承認するまでアシスタントと対話することはできません。

openclaw pairing approve telegram <CODE>

これで完了です。ボットが稼働を開始しました。「何ができる？」と送って、その応答を見てみましょう。

トラブルシューティング： ボットが応答しない場合は、まずopenclaw doctorを実行してください。よくある問題：デーモンが起動していない（openclaw onboard --install-daemonを再度実行してください）、またはTelegramのトークンに誤字がある（~/.openclaw/openclaw.jsonを確認してください）。

インストール後

すぐに行うべき3つのこと：

  1. SOUL.mdを作成する。 任意のテキストエディタで~/.openclaw/workspace/SOUL.mdを開きます。あなたの名前、職業、コミュニケーションの好み、タイムゾーンを記述してください。これはプロンプトではありません — すべての会話で持続するアイデンティティファイルです。

  2. ツールを接続する。 Gmail (Pub/Sub経由)、Google Calendar、Notion、Todoist、Slack — OpenClawはMCPツールとスキルを通じて接続します。ウィザードがすでにこれらのいくつかについて尋ねているかもしれません。

  3. 実際のタスクを実行する。 「ジョークを言って」から始めないでください。「未読メールを要約して優先度順に並べ替えて」や「明日のカレンダーの予定は？何か重複してる？」などを試してみてください。

パスB: クラウドデプロイメント — 自己管理またはAgentPuter

対象者: Macを持っていない方。LinuxまたはWindowsを使用している方。どこからでもアシスタントにアクセスしたい方。「ラップトップが開いている」状態ではなく、真の24時間365日のアップタイムが必要な方。

クラウドデプロイメントには2つのアプローチがあります。自分でサーバーを管理する（完全なコントロール、完全な責任）か、AgentPuterを使用する（AIエージェント専用に構築されたクラウドランタイム、DevOps不要）かです。両方について説明します。

オプションB: Docker Compose (本番環境グレード)

git clone https://github.com/openclaw/openclaw.git
cd openclaw
./docker-setup.sh

利点:

  • プロセス分離 — OpenClawは独自のコンテナで実行されます
  • ワンコマンドでの再起動: docker compose restart
  • 組み込みのログ管理
  • サンドボックスモード: sandbox.mode: "non-main"を設定すると、グループ/チャンネルセッションを分離されたDockerコンテナで実行します

欠点:

  • Docker Engine 24+が必要です
  • デバッグするための抽象化レイヤーがもう1つ増える

Gatewayダッシュボードはhttp://localhost:18789で利用可能ですが、ローカルからのみです。ここからが最も重要な部分です。

リモートアクセス: 正しく設定しましょう

これは任意ではありません。 CVE-2026-25253は、Gatewayポートを直接インターネットに公開すると、トークンの抜き取りが可能になり、リモートコード実行につながることを実証しました。絶対にやめてください。

推奨: Tailscale Serve/Funnel

Tailscaleはプライベートネットワークオーバーレイを提供します。OpenClawは第一級のサポートを提供しています:

{ “gateway”: { “tailscale”: { “mode”: “serve” } } }


- `"serve"` — Tailscaleネットワーク内でのみアクセス可能（最も安全）
- `"funnel"` — 公開HTTPSですが、パスワード認証が必要です (`gateway.auth.mode: "password"`)

**代替案: SSHトンネル**

```bash
ssh -L 18789:localhost:18789 user@your-server-ip

その後、ローカルマシン上の http://localhost:18789 でダッシュボードにアクセスします。

自己管理の難しさ

私は3ヶ月間、自己管理のVPSでOpenClawを運用してきました。以下は私が学んだことです：

  • Node.jsのインストール、systemdの設定、Tailscaleのセットアップ、そしてTLSの処理を自分で行う必要があります。
  • OAuthトークンは期限切れになります。もしあなたが異なるタイムゾーンで寝ている場合、WhatsApp接続は午前3時に切れ、あなたが起きて再認証するまでエージェントは沈黙します。
  • サーバーの再起動後（カーネルアップデート、プロバイダーのメンテナンス）、OpenClawは必ずしもクリーンに復帰するとは限りません。リカバマスクリプトを書くことを覚えるようになります。
  • 複数のエージェントを実行するには、手動でのプロセス分離とリソース割り当てが必要です。

一言で言えば、自己管理のVPSは最大限の自由を与えてくれますが、同時にあなた自身がDevOpsチームでもあるということです。

もし最後の段落を読んで疲れたなら、別の方法があります。

B2: AgentPuter — AIエージェントのために作られたクラウドランタイム

対象者: DevOpsなしでクラウドにデプロイしたい方。マルチエージェントのサポートが必要な方。SLA保証付きの24時間365日の信頼性を重視する方。

AgentPuterとは？

AgentPuterは汎用的なVPSではありません。これは、OpenClaw、ClawBot、MoltBot、そしてカスタムエージェントといったAIエージェント専用に設計された専用のクラウドランタイムです。「AIアシスタント版Heroku」と考えてください。サーバー、コンテナ、デーモンの管理は不要です。シャットダウンすることのないPodを手に入れることができます。

これは、自己管理VPSの4つの問題点を解決します。

自己管理VPSの問題点AgentPuterによる解決策
サーバーの再起動 = エージェントのオフライン自動復旧と稼働時間SLAによりPodは24時間365日稼働
OAuthトークンの有効期限切れ = 手動での再ログイン自動更新付きのサーバーサイドでのトークン管理
エージェントがローカルのCPU/メモリを消費クラウドで分離されたリソース。ローカルマシンへの影響なし
同一ネットワークからのみアクセス可能どこからでも、どのデバイスからでもエージェントを操作

3ステップでのデプロイ

# ステップ1: Podを作成
agentputer create openclaw
# → クラウド環境を割り当て、設定を選択

# ステップ2: サービスを接続
agentputer connect
# → Google、Notion、Slackなどを認証。認証情報はPod内に安全に保存

# ステップ3: OpenClawをデプロイ
agentputer deploy openclaw
# → エージェントが24時間365日稼働開始。WhatsApp、Telegram、Discord — すべてのチャネルが有効になります

所要時間: 約2分

AgentPuterが優れている理由

  • マルチエージェントの並列実行。 ClawBot（パーソナルアシスタント）+ MoltBot（カレンダー/スケジュール管理）+ カスタムリサーチエージェントを、それぞれ分離されたリソースを持つ同じPod内で実行します。
  • 期限切れのない認証。 OAuthトークンはサーバーサイドで自動更新され、維持されます。トークンの有効期限切れで午前3時にWhatsAppの接続が切れることはありません。
  • どこからでもアクセス。 スマートフォン、タブレット、他のコンピューター — あなたがAIを追いかけるのではなく、AIがあなたについてきます。
  • 現在のステータス： アーリーアクセス。agentputer.comで招待コードをリクエストしてください — コードは24時間以内に送信されます。

このパスが存在する理由

パスAでは599ドルとNode.jsが何かを知っていることが必要です。パスB（自己管理）ではSSH、Docker、Tailscaleが必要です。AgentPuterでさえ、はるかにシンプルですが、それでもCLIと招待コードが必要です。

ほとんどの人はnpm install -gを見てタブを閉じてしまいます。

OpenClawの207,000個のスターは、需要が本物であることを証明しています。ボトルネックは製品ではなく、デプロイの障壁です。TinyClawはそれを取り除きます。

TinyClawとは？

TinyClawは、AgentPuterチームが構築したコンシューマー向けの製品です。AgentPuterが「開発者のためのAIエージェントクラウド」であるなら、TinyClawは「みんなのAIエージェントへの入り口」です。

公開までの3つのステップ:

  1. モデルを選択 — Claude Opus 4.6、GPT-5.2、またはGemini 3
  2. チャネルを選択 — Telegram（DiscordとWhatsAppは近日公開予定）
  3. Googleでサインイン → デプロイ完了

サーバー不要。SSH不要。Node.js不要。ターミナル不要。インフラストラクチャは事前に設定されており、あなたに割り当てられるのを待っています。

クリックしてからAIアシスタントとの最初の会話まで：60秒未満。

これで何ができるか

デプロイされると、TinyClawでホストされたOpenClawは次のことができます：

  • メールの読み取り、要約、返信の下書き
  • カレンダーの管理、リマインダーの設定、スケジュールの競合解決
  • ドキュメントの要約、契約書の下書き、請求書の作成
  • 経費の追跡、価格の比較、税務申告の補助
  • 競合調査の実施、ソーシャルメディア投稿の下書き、OKRの追跡
  • ニュースフィードの監視、旅行の予約
  • 自然言語を通じて新しい能力を学習 — 必要なことを伝えるだけ

セットアップ後: あなたのOpenClawを「おもちゃ」から「従業員」に変えるための7つのステップ

どのパスを選択したかにかかわらず、インストールはほんの始まりに過ぎません。ここでは、それを実際に役立つものにする方法を紹介します。

1. SOUL.mdを記述する

場所: ~/.openclaw/workspace/SOUL.md

これはシステムプロンプトではありません。アイデンティティファイルです。次の情報を伝えてください。

  • あなたの名前、役職、そして何をしているか
  • あなたのコミュニケーションスタイル（フォーマル？カジュアル？箇条書き？）
  • あなたのタイムゾーンと勤務時間
  • あなたの好み（「Markdownを好む」、「午前10時より前に会議をスケジュールしない」など）

具体的に記述すればするほど、同じことを繰り返す必要がなくなります。

2. openclaw doctorを実行する

セットアップ後、アップグレードごと、そして何かがおかしいと感じたときはいつでもこれを実行してください。これは、Nodeのバージョン、Gatewayのヘルス状態、チャネルの接続性、モデルへのアクセス、デーモンのステータスなど、すべてをチェックし、何を修正すべきかを正確に教えてくれます。

3. チャットコマンドを学ぶ

これらは、接続されているどのチャネル（Telegram、WhatsApp、Slack、Discord）でも機能します。

コマンド機能
/status現在のモデル、トークン使用量、セッション情報を表示します
/new または /reset会話セッションをリセットします
/compactコンテキストを圧縮してトークンを節約します
/think highディープシンキングモード（Opus 4.6）を有効にします
/verbose onより詳細な応答を返します
/usage full各返信後のトークン消費量を表示します

これらは日常的に使用するコントロールです。/compact だけで、長い会話におけるトークンコストを30～40%節約できます。

4. ツールを接続する

OpenClawはMCP (Model Context Protocol) ツールとスキルを使用して、外部サービスと連携します:

  • Gmail — Pub/Sub経由でリアルタイムのメール通知
  • Google Calendar — イベントの読み取り、作成、変更
  • Notion / Todoist / Linear — タスク管理
  • Slack — チャネルとして、またツールとして
  • ブラウザ — OpenClawは専用のChromeインスタンスを制御できます

5. 記憶の種を植える

永久に記憶される初期コンテキストを与えます:

「毎週月曜日の午前10時にチームミーティングがあります。私の上司の名前はSarahです。回答はMarkdown形式を希望します。現在、Project Atlasの第1四半期ローンチに取り組んでいます。」

これらの事実は記憶に残り、その後のすべての対話に反映されます。

6. 実際のワークフローを実行する

些細なことでテストしないでください。仕事を与えましょう:

  • 「未読メールを要約し、優先度順に並べ替えて」
  • 「今週のカレンダーの予定は？重複があれば指摘して」
  • 「[製品名]の競合上位5社を調査し、比較表を作成して」
  • 「[人物名]からのメールへの返信を下書きして — プロフェッショナルなトーンで、会議は承諾しつつ、代わりに木曜日を提案して」

7. コミュニティスキルをインストールする

設定でClawHubを有効にすると、エージェントが必要に応じて新しいスキルを自動的に検索し、インストールできるようになります。また、SkillsMPで手動で閲覧することもできます — このマーケットプレイスには、Jira連携から航空券の価格追跡まで、あらゆる用途に対応するコミュニティ提供のスキルが数千も揃っています。

よくある質問

APIの費用はいくらですか？ ライトな使用：月額約15ドル。中程度の使用：月額30〜50ドル。ヘビーな使用（Viticciレベル）：月額100〜300ドル。あるいは、Claude Pro（月額20ドル）またはMax（月額100ドル）のサブスクリプションを利用すれば、APIキーを別途管理することなく、OAuth経由で認証できます。

どのモデルが最適ですか？ プロジェクトの作成者はClaude Opus 4.6を強く推奨しています — 長文コンテキストのパフォーマンスが最も優れており、プロンプトインジェクションに対する耐性が最も強力です。GPT-5.2とGemini 3もサポートされています。すでにサブスクリプションをお持ちのモデルを選択してください。

セキュリティは安全ですか？ デフォルトでは、OpenClawはDMペアリングを使用します — 未知の送信者にはペアリングコードが送信され、あなたがopenclaw pairing approveで承認するまでアシスタントと対話することはできません。ローカルでのデプロイでは、すべてのデータはあなたのマシン上に保持されます。リモートアクセスにはTailscaleを使用してください — ゲートウェイポート（18789）を直接インターネットに公開しないでください。

中国語はサポートされていますか？ はい。基盤となるモデルはネイティブで中国語をサポートしています。clawd.org.cnにコミュニティのドキュメントサイトがあり、DeepSeek、Moonshot Kimi、Qwenなどの国内モデルでも動作します。

Windowsで動作しますか？ はい、WSL2（Windows Subsystem for Linux）経由で動作します — これは公式にサポートされており、強く推奨されています。または、TinyClawを使用すれば、ローカルでのセットアップなしでブラウザベースの体験が可能です。

ChatGPT Plusとの違いは何ですか？ ChatGPTはあなたが訪問するのを待ちます。OpenClawは、WhatsApp、Telegram、Slackなど、あなたがどこにいてもあなたに連絡します。ChatGPTにはセッションをまたいだ永続的なメモリがありませんが、OpenClawにはあります。ChatGPTはあなたのファイルやメールを操作できませんが、OpenClawはできます。ChatGPTはVoice WakeやLive Canvasをサポートしていませんが、OpenClawはサポートしています。

何か問題が発生しました。どうすればよいですか？ openclaw doctorを実行してください。自動診断を行い、的を絞った修正手順を提供します。コミュニティのDiscordには5,000人以上のアクティブメンバーがおり、エッジケースの解決を手伝ってくれます。

アップデートするにはどうすればよいですか？

openclaw update --channel stable

最先端の機能が必要な場合は、betaおよびdevチャンネルもあります。

おわりに

4つの道、1つの目的地：あなた自身の24時間365日稼働するAIアシスタントです。

  • Mac Mini：完全なコントロール、音声起動、iMessageを求めるパワーユーザー向け。
  • 自己管理型VPS：ルートアクセスと最大限の柔軟性を求める開発者向け。
  • AgentPuter：クラウドの信頼性、マルチエージェント対応、そしてDevOps不要を求める方向け。
  • TinyClaw：とにかく動けばいいという方向け — 60秒、ターミナル不要。

これらの道は互いに排他的ではありません。まずTinyClawで始めて1分以内にOpenClawを体験し、複数のエージェントを実行したくなったらAgentPuterに移行し、そして最終的に、完全なコントロールの準備ができた時にMac Miniで完全に独立したセットアップを構築することができます。

これは、私たちのエージェントインフラストラクチャシリーズのパート9です。これまで、なぜエージェントが自分自身のコンピューターを必要とするのか、OpenClawのアーキテクチャ、スキルエコシステム、エンタープライズワークフロー、ClawdBotの詳細な解説、ビジネスモデル、そしてそのクリエイターがOpenAIに参加したことの意味について取り上げてきました。本日は「do it yourself」の章でした。

デプロイに成功した方は、コメント欄やDiscordでぜひ教えてください：エージェントに付けた名前と、最初に与えた実際のタスクは何でしたか？
