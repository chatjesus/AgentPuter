OpenClaw 에이전트 실행 5가지 방법 테스트: 실제로 효과적인 방법은 이것입니다.

GitHub 스타 20.7만 개는 모두가 사용해보고 싶어 한다는 의미입니다. 하지만 배포 옵션은 문서화 속도보다 더 빠르게 늘어났습니다. 저희는 2주 동안 셀프 호스팅부터 원클릭 클라우드까지 모든 주요 옵션을 실행하여, 여러분이 사용을 결정하기 전에 어떤 경험을 하게 될지 알 수 있도록 했습니다.

@ AgentPuter Lab
$ 2026년 2월 18일
~ 읽는 시간 16 min

에이전트 인프라 시리즈 10부

OpenClaw는 GitHub 스타 207,000개를 받았습니다. 이 숫자는 하루에 약 2,000개씩 계속 증가하고 있습니다.

이는 많은 사람들이 주목하고 있다는 뜻입니다. 그리고 매주 “원클릭으로 OpenClaw 배포”라는 새로운 서비스가 등장합니다. EasyClaw가 있는데, 사실 이 이름을 사용하는 제품이 5개나 됩니다. InstaClaw도 있습니다. 공식 호스팅 버전인 OpenClaw Cloud도 있습니다. 둘 다 TinyClaw라고 불리는 완전히 다른 두 개의 GitHub 리포지토리도 있습니다. 그리고 애초에 이 프로젝트가 설계된 목적인 자체 하드웨어에 직접 호스팅하는 원래의 방법도 있습니다.

문제는 옵션이 너무 많다는 것이 아닙니다. 대부분의 리뷰가 랜딩 페이지를 지나고 나면 실제 경험이 어떤지에 대해 알려주지 않는다는 점입니다.

그래서 저희가 모두 테스트해 보았습니다. 2주 동안, 5가지 설정으로, 실제 작업을 수행했습니다. 저희가 발견한 내용은 다음과 같습니다.

테스트 내용과 방법

다섯 가지 구성:

  1. 자체 호스팅 Mac Mini M4 — 표준 구성
  2. 자체 호스팅 VPS — Linux 클라우드 서버, SSH 전용
  3. TinyClaw — AgentPuter의 클라우드 런타임, 원클릭 배포
  4. OpenClaw Cloud — 공식 호스팅 버전, 월 $9.99
  5. EasyClaw.ai — 3단계 관리형 호스팅 (월 $5–$49)

각 구성에 대해 다음 항목을 측정했습니다:

  • 첫 메시지까지 걸리는 시간 (처음부터 에이전트와 대화하기까지)
  • 7일간의 안정성 (가동 시간, 메시지 누락, 재시작 동작)
  • 기능 완성도 (실제로 작동하는 기능 대비 추가 설정이 필요한 기능)
  • 실제 작업 성능 (이메일 분류, 캘린더 관리, 웹 리서치)
  • 월간 비용 (보통 수준 사용 시, 매일 약 2시간 활성 사용 기준)

테스트 전반에 걸쳐 Claude Opus 4.6 모델을 사용했으며, 다른 모델만 선택 가능한 경우는 예외로 했습니다. 모든 테스트는 모든 플랫폼에서 가장 안정적인 Telegram을 기본 채널로 사용했습니다.

옵션 1: 자체 호스팅 Mac Mini M4

첫 메시지까지 걸린 시간: 22분
7일 가동 시간: 100%
월간 비용: ~$35 (API) + $0 상각 하드웨어

이것이 기준선이며, 높은 기준을 제시합니다.

설치는 openclaw onboard --install-daemon이라는 단일 명령어로 이루어지며, 마법사가 모든 단계를 안내합니다. 병목 현상은 소프트웨어가 아닙니다. API 키 관리와 Telegram 봇 설정이 문제인데, 이전에 해본 적이 없다면 이 작업에만 약 10분이 걸립니다.

일단 실행되면, Mac Mini 설정은 몇 가지 특정 부분에서 모든 클라우드 옵션을 능가합니다. BlueBubbles를 통한 iMessage 통합이 작동하며, 다른 어떤 것도 이를 따라올 수 없습니다. Voice Wake를 사용하면 네이티브 macOS 앱을 통해 핸즈프리로 에이전트와 대화할 수 있으며, 이는 어떤 클라우드 배포에서도 사용할 수 없습니다. 로컬 파일 시스템 접근은 에이전트가 사용자의 기기를 절대 벗어나지 않는 파일로 작업할 수 있음을 의미합니다.

SOUL.md 파일은 이 설정이 다른 모든 것과 다르게 느껴지기 시작하는 지점입니다. 이것은 시스템 프롬프트가 아닙니다. 에이전트가 매일 시작할 때 읽는 영구적인 정체성 파일입니다. 일주일 동안 이 파일에 내용을 추가한 후, 에이전트는 저의 일정, 소통 방식, 이메일 답장 선호도, 선택 사항으로 간주하는 캘린더 이벤트 등을 알게 되었습니다. 이러한 맥락의 축적은 세션 수준에서 존재하지 않으며, 복리처럼 쌓입니다.

한 가지 성가신 점: BlueBubbles를 통한 iMessage 인증은 까다롭고 테스트 중 2~3주마다 재로그인이 필요했습니다. openclaw doctor 명령어는 하루치 메시지를 잃기 전에 이 문제를 감지하지만, 실제로 실행해야 합니다.

Mac Mini가 있거나 하나 구매할 의향이 있다면, 이것이 정답입니다. 기능의 최대치 면에서는 그 어떤 것도 따라올 수 없습니다.

옵션 2: 자체 호스팅 VPS (Linux)

첫 메시지까지 걸리는 시간: 28분
7일 가동 시간: 100%
월간 비용: ~$35 (API) + $6 (VPS)

루트 접근 권한을 원하는 Linux 사용자와 개발자에게 이 방법은 Mac Mini 설정에서 Voice Wake와 iMessage 기능을 제외한 것과 동일합니다. 설치 방법은 동일하며, 차이점은 데스크톱이 아닌 서버를 유지 관리한다는 것입니다.

장점은 설계상 원격 접근이 가능하다는 점입니다. 노트북이 열려 있는지 여부와 상관없이 에이전트에 접근할 수 있습니다. Tailscale Serve 또는 Funnel(공식 권장 방식)을 사용하면 Gateway 포트를 직접 노출하지 않고도 이를 안전하게 만들 수 있습니다.

단점은 DevOps 오버헤드입니다. 새벽 2시에 에이전트가 응답을 멈추면, 서버에 SSH로 접속하여 로그를 확인해야 합니다. 이러한 작업이 익숙하다면, 이 방법은 훌륭한 선택입니다. 그렇지 않다면, 호스팅 옵션으로 넘어가세요.

한 가지 주목할 점이 있습니다: OpenClaw가 에이전트의 셸 접근을 격리하기 위해 권장하는 Docker 샌드박싱은 VPS 설정에서 눈에 띄는 지연 시간을 추가합니다. 채팅 응답은 괜찮습니다. 파일 작업이나 웹 브라우징을 포함하는 작업은 테스트에서 Mac Mini에 비해 15–30초 더 오래 걸렸습니다. 에이전트 자체로부터의 보안 격리에 대해 걱정하지 않는다면, Docker 없이 실행하는 것이 더 빠릅니다.

Mac Mini와 동일한 성능 한계, 더 높은 유연성, 더 많은 유지보수. 이미 서버를 관리하고 있으며 새로운 것을 배우고 싶지 않은 개발자에게 가장 적합합니다.

옵션 3: TinyClaw

첫 메시지까지의 시간: 48초
7일 가동 시간: ~99.9%
월간 비용: $49.99/월 (모델 포함)

TinyClaw (tinyclaw.dev)는 OpenClaw를 위한 AgentPuter의 클라우드 런타임입니다. 각 사용자는 공유 컴퓨팅의 일부가 아닌 격리된 컨테이너를 할당받습니다. 실질적으로 이는 수백 명의 다른 사용자가 동시에 메시지를 보낼 때 에이전트의 응답 시간이 급격히 저하되지 않음을 의미합니다.

온보딩은 저희가 테스트한 모든 것 중 가장 빨랐습니다 — Google 로그인, Telegram 선택, 봇 토큰 붙여넣기 후 48초 만에 첫 메시지가 도착했습니다. 7일 동안 약 4분간의 유지보수 시간이 한 번 있었으며, 이는 사전에 공지되었습니다.

응답 시간은 일반적인 쿼리에 대해 평균 6–8초였고, 그 수준을 유지했습니다. 이것이 공유 컴퓨팅에 비해 격리된 컨테이너가 갖는 실질적인 이점입니다. 이상적인 조건에서 더 빠르지는 않지만, 조건이 이상적이지 않을 때 일관성을 유지합니다. 가정용 Mac Mini의 인터넷 연결은 변수이지만, 클라우드 컨테이너의 연결은 그렇지 않습니다.

Skills 설치는 안정적이었습니다. ClawHub에서 테스트한 12개의 Skills 중 11개가 문제없이 설치되었습니다. 실패한 하나는 OAuth 리디렉션 구성이 필요한 Spotify 연동 기능으로, 어떤 플랫폼에서든 수동 설정이 필요했을 것입니다.

음성 호출 없음, iMessage 없음, 로컬 파일 시스템 없음. 이것들은 TinyClaw에만 국한된 것이 아니라 클라우드 배포의 구조적 한계입니다. 이러한 기능이 필요하다면 자체 호스팅이 유일한 방법입니다.

에이전트를 하나 이상으로 확장하려는 경우 AgentPuter의 배경이 중요합니다. 동일한 인프라가 하나의 계정으로 여러 OpenClaw 인스턴스를 지원합니다 — 다양한 상황에 맞는 여러 에이전트, 또는 팀원 간의 공유 액세스 등이 가능합니다. 기본 플랜에는 포함되어 있지 않지만, 필요가 커지면 사용할 수 있습니다.

옵션 4: OpenClaw Cloud

첫 메시지까지의 시간: 2분 10초
7일 가동 시간: ~98.4%
월간 비용: $0 (무료 티어, 월 14 컴퓨팅 일) 또는 월 $9.99 Pro

OpenClaw Cloud(open.claw.cloud)는 공식적으로 지원되는 호스팅 버전입니다. 주요 차별점은 무료 티어입니다. Kimi K2.5로 구동되며, 월 14일의 컴퓨팅 시간을 제공합니다. 저희가 테스트했을 때 월 $9.99의 Pro 플랜은 아직 “출시 예정”으로 표시되어 있었습니다. 따라서 이 섹션의 일부는 실제로 사용 가능했던 무료 티어를 기반으로 작성되었습니다.

무료 티어는 데모 그 이상입니다. 사전 설치된 스킬, Telegram 통합, 영구 메모리, 브라우저 자동화 및 전용 가상 머신을 제공받습니다. 14일의 무료 컴퓨팅 기간이 소진되면 VM의 전원은 꺼지지만 데이터는 그대로 유지됩니다. 무료 시간이 더 생기거나 Pro 플랜이 출시되면 다시 전원을 켤 수 있습니다.

Kimi K2.5 모델은 언급할 가치가 있습니다. 이메일 요약, 답장 초안 작성, 캘린더 관리와 같은 대부분의 실용적인 작업에서 테스트 결과 충분한 성능을 보여주었습니다. Claude Opus 4.6과의 격차는 “경쟁사 세 곳을 조사하고, 가격을 비교한 후, 추천안 초안을 작성하라”와 같은 복잡하고 다단계적인 추론에서 나타났습니다. Claude를 사용했을 때 결과물이 눈에 띄게 더 일관성이 있었습니다. 그렇긴 하지만, 가벼운 워크플로우를 실행하는 사용자에게 Kimi K2.5의 가성비는 이의를 제기하기 어렵습니다.

마법사가 아닌 웹 대시보드를 통해 구성하기 때문에 온보딩은 TinyClaw보다 약간 더 오래 걸립니다. Telegram을 연결하는 데 약 2분이 걸렸습니다. 스킬 관리가 완전히 노출되어 있어, 원하는 바를 명확히 알 때는 좋지만 그렇지 않을 때는 혼란스러울 수 있습니다.

실제 OpenClaw를 경험할 수 있는 가장 저렴한 방법입니다. 무엇이든 결정하기 전에 시험해보고 싶다면 최고의 선택입니다.

옵션 5: EasyClaw.ai

첫 메시지까지 걸리는 시간: 4분
7일 가동 시간: 99.1%
월간 비용: 티어에 따라 $19–$49

EasyClaw.ai의 가장 큰 특징은 브라우저 기반 데스크톱 액세스입니다. 즉, 브라우저 탭에서 에이전트의 컨테이너 환경을 전체적으로 볼 수 있습니다. 브라우저 인증이 필요한 계정에 로그인하고, 도구를 설치하며, 구성 파일을 수정할 수 있습니다. 관리형 플랫폼에서는 보통 허용되지 않는 작업들입니다.

저희는 이 기능을 사용하여 브라우저 흐름을 통한 인증이 필요한 Gmail 통합을 설정했는데, 이 작업은 EasyClaw에서는 간단하지만 해당 기능이 없는 플랫폼에서는 불가능합니다.

가격 티어는 $5(개발자, 자체 VPS 사용), $19(관리형), 그리고 상위 등급 지원이 포함된 $49(완전 관리형)로 구성됩니다. 월 $49는, 직접 관리가 필요 없는 유지보수를 진정으로 원하지 않는 한, 자체 관리형 VPS를 사용하는 것이 재정적으로 더 합리적인 수준의 비용입니다.

이름에 대한 참고 사항: “EasyClaw”라는 이름은 서로 다른 개발자들이 만든 최소 5개의 다른 제품에서 사용되고 있습니다 — easyclaw.ai, easyclaw.app, easyclaw.pro 및 몇 가지 다른 제품들이 있습니다. 저희가 테스트한 것은 easyclaw.ai입니다. 이름이 비슷한 다른 서비스 중 적어도 하나에 대해 2026년 2월 초 커뮤니티에서 보안 문제가 제기되었습니다. 어디서든 자격 증명을 입력하기 전에 올바른 URL에 접속했는지 확인하십시오.

오픈소스 파생 버전 현황

호스팅 서비스 외에도, 더 좁은 사용자층을 대상으로 하지만 오픈소스 파생 버전들에 대해 알아볼 가치가 있습니다.

**TinyClaw (jlia0 버전)**은 OpenClaw 개념을 약 400줄의 셸 스크립트로 재구현한 것입니다 — Node.js와 전체 프레임워크 대신 Claude Code와 tmux로 빌드되었습니다. Discord, WhatsApp, Telegram에서 여러 격리된 에이전트를 병렬로 실행하며, 경쟁 상태를 방지하는 파일 기반 메시지 큐를 통해 조정합니다. 2026년 2월 기준으로 약 2,000개의 GitHub 스타를 받았으며, 코드베이스가 작아 오후 반나절이면 읽을 수 있을 정도입니다. 내부에서 실제로 어떤 일이 일어나는지 이해하고 싶거나 제한된 환경에 에이전트를 임베드해야 하는 경우, 가장 직접적인 방법입니다.

**TinyClaw (warengonzaga 버전)**은 완전히 다른 프로젝트입니다 — TypeScript로 재작성되었으며, 스스로를 명시적으로 “OpenClaw와 완전히 독립적인 제품이자 대안”으로 포지셔닝합니다. 플러그인 아키텍처, 자가 개선 메모리, 그리고 LLM 비용을 줄이기 위한 스마트 쿼리 라우팅을 강조합니다. 작업 실행보다는 “개인 AI 동반자”에 더 중점을 둡니다. 주목할 가치가 있지만 아직 초기 단계입니다.

이 둘 모두 호스팅 서비스와 직접 경쟁하지는 않습니다. 이는 기본 메커니즘을 이해하고 수정하고자 하는 개발자들을 위한 도구입니다.

실제 권장 사항

에이전트를 한 번도 실행해 본 적이 없다면 OpenClaw Cloud로 시작하세요. 무료 티어는 비용을 지불하거나 터미널을 건드릴 필요 없이 14일 동안 이것이 정말로 원하는 것인지 파악할 기회를 제공합니다.

안정적인 실행을 원하신다면 TinyClaw가 가장 깔끔한 업그레이드입니다. 격리된 컨테이너, 일관된 성능, 가장 빠른 온보딩을 제공합니다. 나중에 여러 에이전트나 팀 액세스를 원하게 되더라도, 이를 위한 인프라가 이미 구축되어 있습니다.

데이터 주권이 중요하거나, Voice Wake가 필요하거나, iMessage가 중요하다면 자체 호스팅하세요. Mac Mini가 명백한 하드웨어 선택입니다 — $599, 조용하고, 유휴 상태에서 3–4W를 소모하며, macOS를 네이티브로 실행합니다. 어떤 클라우드 옵션도 로컬 우선 방식이 제공하는 것을 줄 수는 없습니다.

작동 방식을 이해하고 싶은 개발자라면 다른 어떤 것보다 먼저 jlia0 TinyClaw 코드를 읽어보세요. 400줄의 셸 코드가 어떤 문서보다도 내부 동작에 대해 더 많은 것을 알려줄 것입니다.

솔직한 평가

“작동하는 것”과 “유용한 것”은 같은 것이 아닙니다. 저희가 테스트한 모든 옵션은 첫 한 시간 안에 작동했습니다. 유용하게 만드는 데는 더 오랜 시간이 걸렸습니다 — SOUL.md가 컨텍스트를 축적해야 했고, 실제로 사용하는 도구를 연결해야 했으며, 데모 프롬프트가 아닌 중요한 작업을 에이전트에게 부여해야 했습니다. 호스팅 옵션은 시작하기 더 쉽습니다. 자체 호스팅 옵션은 일단 시작하고 나면 더 많은 것을 활용할 수 있게 해줍니다.

Skills 생태계는 가장 큰 미해결 과제입니다. 보안 회사인 Koi Security가 2026년 2월 초 ClawHub를 감사하여 분석된 2,857개의 Skills 중 341개의 악성 Skills를 발견했습니다 — 이는 카탈로그의 약 12%에 해당하며, 대부분은 적발되기 전 일주일 동안 314개의 악성 Skills를 게시한 단일 공격자 계정에서 비롯되었습니다. 이후 OpenClaw는 검토 프로세스를 추가했지만, 카탈로그가 너무 커서 수동으로 감사하기는 어렵습니다. 커뮤니티 Skills는 브라우저 확장 프로그램처럼 다루세요: 유용하고, 종종 훌륭하며, 시스템 접근을 요청하는 것을 설치하기 전에는 소스를 빠르게 훑어볼 가치가 있습니다.

GitHub 스타 207K는 무언가 제대로 되었다는 것을 의미합니다. 이 특정한 것이 당신에게 맞는지는 랜딩 페이지가 아닌, 일주일은 걸려야 답할 수 있는 질문입니다.
