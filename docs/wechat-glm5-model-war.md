# GLM-5 抄了 DeepSeek 的作业，但这恰好证明了一件事

> 当所有模型都在变成同一个架构，AI 的胜负手就不在模型上了。

---

GLM-5 的架构泄露了。

不是智谱自己说的，是社区从 vLLM 推理框架的 PR 里挖出来的。结论很直接：**GLM-5 采用了 DeepSeek-V3/V3.2 同款架构** —— 稀疏注意力（DSA）、多 Token 预测（MTP）、MoE 混合专家。

745B 总参数，256 个专家，每次推理激活 8 个（约 44B），稀疏度 5.9%。上下文窗口 202K。

与此同时，OpenRouter 上悄悄出现了一个匿名免费模型「Pony Alpha」—— 编程和推理能力极为强劲，91% 以上的社区用户判断它是 **GLM-5 的测试版**。

受这些消息影响，**智谱港股两日暴涨 60%**。

这件事本身很热闹。但更值得想的是它背后的趋势：**当中国最大的独立大模型公司选择复用 DeepSeek 的架构，这说明什么？**

---

## 模型正在趋同

先看一组对比：

| | DeepSeek-V3.2 | GLM-5（泄露） |
|---|---|---|
| 架构 | MoE + DSA + MTP | MoE + DSA + MTP |
| 总参数 | 671B | 745B |
| 激活参数 | ~37B | ~44B |
| 稀疏度 | 5.4% | 5.9% |
| 上下文 | 128K | 202K |

架构几乎一模一样。差异只是参数量大了 11%，上下文窗口长了 58%。

这不是智谱"抄作业"—— 这是一个合理的工程决策。DeepSeek-V3 的架构是开源的，经过了 vLLM、SGLang 等推理框架的充分优化，部署门槛低，性能验证充分。在这个基础上做增量改进（更多参数、更长上下文），远比从零设计新架构高效。

但这恰好揭示了一个更大的信号：**大模型的架构层正在标准化。**

DeepSeek 开源了架构 → 智谱跟进 → 开源社区的推理优化自动适配 → 下一家公司更容易跟进。这不是一家公司的选择，是一个行业的收敛。

## 春节档的 AI 混战说明了什么

2026 年 2 月，至少四个重量级模型在同一个窗口期发布或更新：

- **DeepSeek** —— 新模型（V3.2-Speciale 已经在 IMO 和 IOI 上拿了金牌）
- **智谱 GLM-5** —— 架构泄露 + Pony Alpha 疑似测试版
- **通义 Qwen 3.5** —— 阿里的下一代
- **MiniMax M2.2** —— 新版本即将更新
- **Claude Opus 4.6** —— 2月5日刚发布，1M 上下文窗口

同时，Anthropic 在 2025 年底把 MCP 协议捐给了 Linux 基金会，AWS、Google、Microsoft、Bloomberg、Cloudflare 全部白金赞助。

看到规律了吗？

**模型端：军备竞赛，疯狂内卷，架构趋同。**

**协议端：走向标准化，全行业共建。**

当模型变成水电煤，真正稀缺的就不是模型了。

## 模型不是壁垒，基础设施才是

回到 GLM-5。

假设它确实达到了 DeepSeek-V3.2 的水平（架构一样，参数更大，上下文更长），那中国市场就有了**两个** DeepSeek 级别的模型。加上 Qwen 3.5 和 Claude Opus 4.6，全球范围内达到"足够好"水平的模型已经有**五个以上**。

这对做 AI 应用的人来说是天大的好消息。模型竞争意味着：
- **价格暴跌** —— DeepSeek 已经把成本打到了 Claude 的 1/10
- **部署更容易** —— 架构趋同意味着推理框架优化通用
- **切换成本趋零** —— OpenRouter 一个 API，所有模型随切

但这对做 AI Agent 平台的人来说，意味着模型不是壁垒。

**真正的壁垒是什么？**

是你的 Agent 知道怎么做你公司的季度报告（**Skills**）。

是你的 Agent 在第 7 步失败时能自动回滚而不是崩溃（**Gateway**）。

是你的 Agent 在审查合同时不会把内容泄露到邮件 Skill 里（**安全隔离**）。

是你的 Agent 处理的 202K tokens 上下文里有没有被投毒的 Skill（**Schema 验证**）。

这些东西跟你用的是 Claude、DeepSeek 还是 GLM-5，**一点关系都没有**。

## 我们在做的事

AgentPuter 做的不是模型。我们做的是**模型无关的 Agent 运行时**。

你选 Claude Opus 4.6 当大脑？可以。

你选 DeepSeek-V3.2 追求性价比？可以。

你选 GLM-5 因为你是智谱生态的开发者？可以。

无论哪个模型，你的 Agent 都需要：

- **Skills** —— 编码了你公司业务逻辑的领域知识，不是通用 prompt
- **Gateway** —— 管理会话、编排工具调用、处理失败和重试、执行权限
- **MCP 工具** —— 连接 CRM、邮件、日历、文件系统的标准化接口
- **安全沙箱** —— 隔离每个任务的数据和权限

模型是大脑。我们建的是骨骼、肌肉和免疫系统。

GLM-5 抄了 DeepSeek 的架构，正好证明了这一点：**大脑在趋同。身体才是差异化的战场。**
