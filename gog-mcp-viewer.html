MCP 工具能力列表
📧
Gmail
邮件搜索与发送
  • gmail search 用 Gmail 查询语法搜索邮件，支持时间范围、发件人等过滤条件，--max 限制结果数
  • gmail send 发送邮件，支持 --to、--subject、--body 参数，操作前会请求确认
📅
Calendar
日历事件管理
  • calendar events 按 ISO 时间范围查询指定日历的事件列表，适用于时间段报告和集成
  • calendar create 创建新日历事件，支持标题、时间、参与者等字段，创建前确认
💾
Drive
云端文件查询与管理
  • drive search 按 Drive 查询语法搜索文件，支持 --max 限制，JSON 输出文件元数据
  • drive list 列出 Drive 文件目录，用于备份审计和文件清单同步
👥
Contacts
联系人管理
  • contacts list 列出联系人，支持 --max 限制，JSON 输出可直接导入其他系统进行迁移同步
📊
Google Sheets
表格读写与批量操作
  • sheets get 读取指定区域单元格数据，支持 A1 表示法，--json 输出
  • sheets update 更新单元格数据，通过 --values-json 传入结构化二维数组，支持 USER_ENTERED 模式
  • sheets append 追加新行到表格末尾，支持 --insert INSERT_ROWS 策略，适合 ETL 数据管道
  • sheets clear 清空指定区域内容，不删除格式样式，用于数据重置
  • sheets metadata 获取表格结构信息：页签名称、行列范围、表格属性等
📝
Google Docs
文档导出与读取
  • docs export 导出文档为指定格式（txt / pdf / html），保存到本地路径，--out 指定目标位置
  • docs cat 直接输出文档全文内容到 stdout，适合快速阅读和文本处理管道
  • docs copy 复制文档创建副本，用于模板快速生成新文档
全局标志 & 脚本特性
🔧
--json
所有输出以机器可读 JSON 格式返回，适合 CI/CD 管道集成
🤖
--no-input
完全非交互模式，不等待用户确认，适合自动化脚本和定时任务
👤
GOG_ACCOUNT
通过环境变量指定默认账号，无需每次传 --account 参数
📋
--values-json
通过 JSON 数组传递 Sheets 数据，避免 shell 转义问题，推荐在脚本中使用
🔢
--max N
限制搜索/列表结果数量，防止大数据集过载
📄
--format
docs export 支持 txt、pdf、html 等格式输出
认证初始化（一次性配置）
# 1. 导入 OAuth 凭据（从 Google Cloud Console 下载）
gog auth credentials /path/to/client_secret.json

# 2. 添加账号并授权服务
gog auth add you@gmail.com --services gmail,calendar,drive,contacts,sheets,docs

# 3. 确认授权列表
gog auth list

# 4. 设置默认账号（避免每次传参）
export GOG_ACCOUNT=you@gmail.com
