## 這件事對未來十年意味著什麼

Clawdbot 不只是一個產品故事。
當每個人都有一個 24 小時運行的 Agent，而這個 Agent 的核心能力之一是瀏覽器自動化（本質上就是爬蟲），網際網路的流量組成會劇烈變化。一個網站 50% 甚至更多的訪客可能不再是人。
當 Agent 能搞定行政、排程、資料擷取、郵件初稿這些無聊但必要的中間層任務，一個知道*做什麼*和*為什麼做*的人就能指揮一支 Agent 部隊去執行。競爭優勢的來源，從執行速度轉向
**當一個 Agent 有了記憶、有了心跳、有了操作世界的手——它在什麼時候不再只是工具？**

這個問題，我們會想很久。
