Skills y ClawHub

OpenClaw incluye más de 50 Skills integradas y más de 565 Skills de la comunidad a través de ClawHub.
AgentPuter precarga las Skills más populares y te permite gestionarlas desde el Dashboard.

$ agentputer skills list

Integradas: 50 Skills cargadas

ClawHub: 565+ disponibles

Ejecuta: agentputer skills install <name>

Lo que construirás:

Ajustes del Pod

Un Pod es tu instancia de servidor en AgentPuter: un contenedor siempre activo que ejecuta OpenClaw. Configura la región, los recursos y el almacenamiento desde el Dashboard.

$ agentputer pod info mi-agente

Región: us-east-1

CPU: 2 vCPU | RAM: 2 GB

Almacenamiento: 40 GB SSD (2.1 GB usados)

OpenClaw: v2026.2.6 (actualización auto: activada)

Estado: en ejecución (tiempo activo: 14d 6h)

Entorno y Secretos

Configura las claves API de tu modelo de IA y otros secretos. AgentPuter los almacena cifrados y los inyecta en tu instancia de OpenClaw, sin necesidad de acceder por SSH para editar archivos JSON.

$ agentputer config set agent.model=anthropic/claude-opus-4-6

✓ Modelo actualizado

$ agentputer secrets set ANTHROPIC_API_KEY=sk-ant-...

✓ Secreto guardado (cifrado)

Modelo recomendado: Anthropic Claude Opus 4.6 (mejor contexto largo + anti-inyección). Necesitas tu propia clave API o una suscripción a Anthropic Pro (20 $/mes).

Acceso SSH

Los usuarios avanzados pueden conectarse por SSH directamente a su Pod para configuración avanzada, depuración o para ejecutar comandos de la CLI de OpenClaw.

$ agentputer ssh mi-agente

Conectando a pod-abc123...

root@pod-abc123:~#

# Ahora puedes ejecutar comandos de openclaw directamente:

$ openclaw doctor

✓ Todas las comprobaciones superadas

CONCEPTOS CLAVE

Seguridad y Privacidad

AgentPuter aísla cada Pod en su propio contenedor. Tus datos permanecen en tu Pod.
OpenClaw proporciona DM Pairing para controlar quién puede enviar mensajes a tu agente.

Aislamiento de Pod

Contenedor dedicado por usuario. Sin recursos compartidos.

DM Pairing

Autenticación integrada de OpenClaw. Los remitentes desconocidos deben ser aprobados.

Secretos Cifrados

Claves API almacenadas de forma cifrada, nunca expuestas a los modelos.

Modo Sandbox

El Sandbox de OpenClaw limita a qué pueden acceder las Skills.

Solución de Problemas

Problemas comunes y cómo solucionarlos.

¿El bot no responde?

Comprueba el estado del Pod: agentputer status. Verifica que tu clave API del modelo esté configurada y sea válida.

¿No llega el código de DM Pairing?

Asegúrate de que el Token del bot sea correcto. Prueba: openclaw doctor vía SSH.

¿El Pod no arranca?

Revisa los logs: agentputer logs mi-agente. Contacta con soporte si el problema persiste.

Coste y Uso

Tus costes provienen de dos fuentes:

① AgentPuter (Infraestructura)

Tarifa de hosting del Pod. Cubre cómputo, almacenamiento, red, actualizaciones automáticas y acceso al Dashboard.

② API del Modelo (Tu suscripción)

Uso del modelo de IA. Tú aportas tu propia clave API (p. ej., Anthropic Pro 20 $/mes).
AgentPuter proporciona un panel de monitorización de costes para que siempre sepas cuánto gastas.

$ agentputer usage mi-agente

Este mes: 1,247 mensajes | ~8,40 $ de coste de API

Límite de presupuesto: 50 $/mes | Usado: 16,8%
