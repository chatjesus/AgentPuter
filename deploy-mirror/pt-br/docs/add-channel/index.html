Adicionar Canais

Conecte o OpenClaw às suas plataformas de mensagens.
O OpenClaw suporta mais de 15 canais. Adicione um ou vários.

1.0 Canais Suportados

✈️ Telegram

O mais popular. Crie um bot via @BotFather, cole o token.

Tempo de configuração: ~2 min Adicionar Telegram →
💬 WebChat

Integrado. Nenhuma configuração necessária. Acesse pelo Dashboard.

Tempo de configuração: 0 min (auto) Já ativo ✓

Em breve na versão 1.1+

📱 WhatsApp 📢 Slack 🎮 Discord 🔐 Signal 📧 Google Chat 🍎 iMessage 💼 Teams 🌐 Matrix

✈️ Adicionar Telegram — Passo a Passo

1

Crie um Bot via @BotFather

Abra o Telegram → pesquise por @BotFather → /newbot → dê um nome ao seu bot → obtenha o token

2

Cole o Token no Dashboard

Dashboard → Canais → Adicionar Telegram → cole o token → Conectar

123456:ABCDefGhIJKlmNoPQRsTUVwxyz...
3

DM Pairing (Segurança do OpenClaw)

Envie qualquer mensagem para o seu bot → receba o código de pareamento → aprove no Dashboard

⚠️ O DM Pairing é um recurso de segurança do OpenClaw

Remetentes desconhecidos recebem um código de pareamento. Aprove via Dashboard ou CLI:
agentputer pairing approve telegram <code>

✓

Telegram Conectado!

Seu bot @my_agent_bot agora está vinculado ao seu agente OpenClaw.
Envie qualquer mensagem para começar a conversar. Tente: 'O que você pode fazer?'

Ou via CLI:

$ agentputer channels add telegram
