Agent Skills: AI 세계의 앱 스토어가 모습을 갖추다

17만 개 이상의 오픈소스 Skills, 사라진 Gateway 계층, 그리고 에이전트 플랫폼이 Windows의 전략을 따르는 이유.

@ AgentPuter Lab
$ 2026년 2월 9일
~ 읽는 시간 15분

지난 두 개의 포스트에서 저희는 OpenClaw에 대해 깊이 다루었습니다. 그것이 무엇인지, Brain-Body-Soul 아키텍처가 어떻게 작동하는지, 그리고 1,100개의 노출된 Gateway 포트에서 얻은 보안 교훈에 대해 이야기했습니다.

하지만 저희가 완전히 설명하지 않고 계속 언급했던 한 가지가 있습니다: 바로 Skills입니다.

OpenClaw는 100개 이상의 내장 Skills와 함께 제공됩니다. Anthropic은 Skills를 오픈 표준으로 만들었고, SkillsMP는 이미 17만 개 이상의 오픈소스 Skills를 호스팅하고 있습니다.

이 숫자들은 더 큰 질문을 제기합니다:

Skills란 정확히 무엇일까요? MCP와는 어떤 관련이 있을까요? 그리고 이것이 정말 AI 세계의 ‘앱 스토어의 순간’일까요?

하나씩 정리해 보겠습니다.

I. Skills가 해결하는 기본적인 문제

ChatGPT에게 무언가를 해달라고 요청하면, 어떻게 그 작업을 처리할까요?

학습 데이터에 기반해 즉흥적으로 처리합니다. 운이 좋으면 결과물이 괜찮지만, 그렇지 않으면 자신감 있게 틀린 답을 내놓습니다. 여러분의 특정 맥락, 산업 관행, 또는 워크플로우를 모르기 때문입니다.

Skills는 바로 이 문제를 해결하기 위해 존재합니다.

Skill은 에이전트에게 ‘이런 종류의 작업을 마주치면, 이 단계를 따르고, 이 도구들을 사용하고, 이런 엣지 케이스들을 조심하라’고 알려주는 지침서입니다.

즉흥적으로 처리하는 대신, 에이전트는 레시피를 따릅니다.

II. Skill은 실제로 어떤 모습일까요?

놀라실 수도 있지만, Skill은 그저 Markdown 파일이 들어있는 폴더일 뿐입니다.

SKILL.md라는 이름의 파일입니다. 이름, 설명, 라이선스, 작성자 등 몇 줄의 YAML 메타데이터로 시작합니다. 그리고 본문은 일반 Markdown으로 작성됩니다. 단계별 지침, 입출력 예시, 흔한 함정을 처리하는 방법 등이 포함됩니다.

필요하다면 폴더에 스크립트(예: Python 파일), 참조 문서, 템플릿 파일 등을 포함할 수도 있습니다.

그게 전부입니다. 설치할 SDK도, 띄울 서버도, 구현할 JSON-RPC 프로토콜도 없습니다.

폴더 = skill. Markdown = 인터페이스.

이것이 바로 생태계가 이토록 빠르게 성장하는 이유입니다. Skill을 만드는 데 대한 진입 장벽이 터무니없이 낮기 때문입니다. Markdown을 작성할 수 있다면, Skill도 작성할 수 있습니다.

III. 누가 Skills를 사용하고 있나요?

Anthropic은 원래 agentskills.io에서 Skills를 오픈 표준으로 공개했습니다. 하지만 이것은 Anthropic 전용 포맷이 아닙니다. 호환성 목록은 매우 넓어졌습니다:

  • Claude Code — Anthropic의 자체 코딩 에이전트. Skills가 핵심 확장 메커니즘입니다.
  • OpenAI Codex CLI / ChatGPT — OpenAI가 동일한 표준을 채택했습니다. 이제 Skills는 Anthropic과 OpenAI 생태계 모두에서 작동합니다.
  • Cursor — 가장 인기 있는 AI 코딩 도구 중 하나. 네이티브 Skills 검색 및 로딩을 지원합니다.
  • GitHub Copilot — Microsoft의 생태계. 이미 호환됩니다.
  • Windsurf — Cognition의 AI 개발 환경입니다.
  • OpenClaw — 저희가 분석해 온 프로젝트. 100개 이상의 내장 Skills를 갖추고 있습니다.

Skill을 한 번 작성하면, 이 모든 곳에서 작동합니다. Anthropic과 OpenAI가 동일한 오픈 포맷을 지원하는 것은 거의 전례 없는 일입니다. 이 두 회사는 거의 모든 것에 대해 의견이 다릅니다. 이것만 봐도 통합에 대한 압력이 얼마나 강한지 알 수 있습니다. 1년 전만 해도 모든 플랫폼이 자체 플러그인 포맷을 가지고 있었습니다. 이제는 공유된 표준이 있습니다.

IV. Skills vs MCP: 더 이상 혼동하지 마세요

이 질문은 끊임없이 나옵니다. 이제 명확히 정리해 보겠습니다.
