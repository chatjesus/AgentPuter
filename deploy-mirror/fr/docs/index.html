Skills & ClawHub

OpenClaw inclut plus de 50 Skills intégrés et plus de 565 Skills communautaires via ClawHub.
AgentPuter précharge les Skills populaires et vous permet de les gérer depuis le Dashboard.

$ agentputer skills list

Intégrés : 50 Skills chargés

ClawHub : 565+ disponibles

Exécutez : agentputer skills install <nom>

Ce que vous allez construire :

votre-terminal

$ agentputer create my-agent

✓ Pod prêt (OpenClaw v2026.2.6 pré-installé)

✓ Passerelle en cours d'exécution (ws://pod-abc123:18789)

$ agentputer channels add telegram

✓ Bot @my_agent_bot connecté

$ agentputer status

✓ Pod : en exécution | OpenClaw : v2026.2.6 | Canaux : 1

✓ Skills : 12 actifs | ClawHub : connecté

🔄

CONFIGURER

Paramètres du Pod

Un Pod est votre instance de serveur AgentPuter — un conteneur toujours actif exécutant OpenClaw. Configurez la région, les ressources et le stockage depuis le Dashboard.

$ agentputer pod info my-agent

Région : us-east-1

CPU : 2 vCPU | RAM : 2 Go

Stockage : 40 Go SSD (2.1 Go utilisés)

OpenClaw : v2026.2.6 (mise à jour auto : activée)

Statut : en exécution (disponibilité : 14j 6h)

Environnement & Secrets

Configurez vos clés API de modèle d'IA et autres secrets. AgentPuter les stocke de manière chiffrée et les injecte dans votre instance OpenClaw — pas besoin de vous connecter en SSH pour éditer des fichiers JSON.

$ agentputer config set agent.model=anthropic/claude-opus-4-6

✓ Modèle mis à jour

$ agentputer secrets set ANTHROPIC_API_KEY=sk-ant-...

✓ Secret stocké (chiffré)

Modèle recommandé : Anthropic Claude Opus 4.6 (meilleur pour le contexte long + anti-injection). Vous avez besoin de votre propre clé API ou d'un abonnement Anthropic Pro (20 $/mois).

Accès SSH

Les utilisateurs avancés peuvent se connecter en SSH directement à leur Pod pour une configuration avancée, du débogage ou pour exécuter des commandes CLI OpenClaw.

$ agentputer ssh my-agent

Connexion à pod-abc123...

root@pod-abc123:~#

# Vous pouvez maintenant exécuter les commandes openclaw directement :

$ openclaw doctor

✓ Toutes les vérifications ont réussi

COMPRENDRE

Sécurité & Confidentialité

AgentPuter isole chaque Pod dans son propre conteneur. Vos données restent dans votre Pod.
OpenClaw fournit le DM Pairing pour contrôler qui peut envoyer des messages à votre agent.

Isolation du Pod

Conteneur dédié par utilisateur. Pas de ressources partagées.

DM Pairing

Authentification intégrée d'OpenClaw. Les expéditeurs inconnus doivent être approuvés.

Secrets chiffrés

Clés API stockées chiffrées, jamais exposées aux modèles.

Mode Sandbox

Le Sandbox d'OpenClaw limite ce à quoi les Skills peuvent accéder.

Dépannage

Problèmes courants et comment les résoudre.

Le bot ne répond pas ?

Vérifiez le statut du Pod : agentputer status. Assurez-vous que votre clé API de modèle est définie et valide.

Le code de DM Pairing n'arrive pas ?

Assurez-vous que le token du bot est correct. Essayez : openclaw doctor via SSH.

Le Pod ne démarre pas ?

Vérifiez les logs : agentputer logs my-agent. Contactez le support si le problème persiste.

Coûts & Utilisation

Vos coûts proviennent de deux sources :

① AgentPuter (Infrastructure)

Frais d'hébergement du Pod. Couvre le calcul, le stockage, le réseau, les mises à jour automatiques et l'accès au Dashboard.

② API du modèle (Votre abonnement)

Utilisation du modèle d'IA. Vous apportez votre propre clé API (ex: Anthropic Pro 20 $/mois).
AgentPuter fournit un tableau de bord de suivi des coûts pour que vous connaissiez toujours vos dépenses.

$ agentputer usage my-agent

Ce mois-ci : 1 247 messages | ~8,40 $ de coût API

Limite de budget : 50 $/mois | Utilisé : 16,8 %

✓ Dans le budget
