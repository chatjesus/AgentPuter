Kanäle hinzufügen

Verbinde OpenClaw mit deinen Messaging-Plattformen.
OpenClaw unterstützt über 15 Kanäle. Füge einen oder mehrere hinzu.

1.0 Unterstützte Kanäle

✈️ Telegram

Am beliebtesten. Erstelle einen Bot über @BotFather, füge den Token ein.

Einrichtungszeit: ~2 Min. Telegram hinzufügen →
💬 WebChat

Integriert. Keine Einrichtung nötig. Zugriff über das Dashboard.

Einrichtungszeit: 0 Min. (automatisch) Bereits aktiv ✓

Kommt in 1.1+

📱 WhatsApp 📢 Slack 🎮 Discord 🔐 Signal 📧 Google Chat 🍎 iMessage 💼 Teams 🌐 Matrix

✈️ Telegram hinzufügen – Schritt für Schritt

1

Bot über @BotFather erstellen

Telegram öffnen → @BotFather suchen → /newbot → Bot benennen → Token erhalten

2

Token im Dashboard einfügen

Dashboard → Kanäle → Telegram hinzufügen → Token einfügen → Verbinden

123456:ABCDefGhIJKlmNoPQRsTUVwxyz...
3

DM Pairing (OpenClaw-Sicherheit)

Sende eine beliebige Nachricht an deinen Bot → Kopplungscode erhalten → im Dashboard genehmigen

⚠️ DM Pairing ist eine Sicherheitsfunktion von OpenClaw

Unbekannte Absender erhalten einen Kopplungscode. Genehmige über das Dashboard oder die CLI:
agentputer pairing approve telegram <code>

✓

Telegram verbunden!

Dein Bot @my_agent_bot ist jetzt mit deinem OpenClaw-Agenten verknüpft.
Sende eine beliebige Nachricht, um zu chatten. Probiere: 'Was kannst du tun?'

Oder über die CLI:

$ agentputer channels add telegram

? Bot token: 123456:ABCDefGhIJKlmNoPQRsTUVwxyz

✓ Telegram-Kanal zum Pod my-agent hinzugefügt
