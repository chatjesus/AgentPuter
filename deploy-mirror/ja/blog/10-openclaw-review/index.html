OpenClawエージェントの実行方法5選を徹底検証。実際に使えるのはどれか？

GitHubで20万7000スターを獲得し、誰もが試したがっています。しかし、デプロイの選択肢はドキュメントの整備を上回る速さで増殖しています。私たちは2週間を費やし、セルフホストからワンクリッククラウドまで、あらゆる主要な選択肢を試しました。あなたがコミットする前に、何が得られるのかをこの記事で解説します。

エージェントインフラストラクチャシリーズ 第10回

OpenClawはGitHubで20万7000のスターを獲得しています。その数は1日におよそ2,000ずつ増え続けています。

これは、多くの人々が注目していることを意味します。そして毎週のように、「ワンクリックでOpenClawをデプロイ」とうたう新しいサービスが登場します。EasyClawというサービスがありますが、実際にはその名前を使った5つの異なる製品が存在します。InstaClawもあります。公式のホスト版であるOpenClaw Cloudもあります。TinyClawと呼ばれる、全く異なる2つのGitHubリポジトリも存在します。そして、元々の方法である、自身のハードウェアでのセルフホスティングがあります。これは、そもそもこのプロジェクトが設計された目的でもあります。

問題は選択肢が多すぎることではありません。ほとんどのレビューが、ランディングページを過ぎた後の実際の使用感がどのようなものかを伝えていないことです。

そこで、私たちはそれらすべてをテストしました。2週間かけて、5つのセットアップで実際のタスクを実行。その結果わかったことをお伝えします。

検証内容と方法

5つの構成：

  1. セルフホストの Mac Mini M4 — 標準的なセットアップ
  2. セルフホストの VPS — Linux クラウドサーバー、SSHのみ
  3. TinyClaw — AgentPuter のクラウドランタイム、ワンクリックデプロイメント
  4. OpenClaw Cloud — 公式ホスト版、月額$9.99
  5. EasyClaw.ai — 3段階のマネージドホスティング（月額$5～$49）

各セットアップについて、以下の項目を測定しました：

  • 最初のメッセージまでの時間（ゼロからエージェントと対話を開始するまで）
  • 7日間にわたる信頼性（稼働時間、メッセージの欠落、再起動時の挙動）
  • 機能の完全性（実際に機能する機能と、追加設定が必要な機能の比較）
  • 実タスクのパフォーマンス（メールのトリアージ、カレンダー管理、ウェブ調査）
  • 中程度の使用量における月額コスト（1日あたり約2時間のアクティブな使用）

モデルは、他のモデルしか選択肢がない場合を除き、一貫して Claude Opus 4.6 を使用しました。すべてのプラットフォームで最も安定しているため、全テストで主要なチャネルとして Telegram を使用しました。

オプション1：セルフホストのMac Mini M4

最初のメッセージまでの時間： 22分
7日間の稼働率： 100%
月額費用： 約$35 (API) + $0 (償却済みハードウェア)

これがベースラインであり、高い基準を設定します。

インストールは openclaw onboard --install-daemon という単一のコマンドで、ウィザードがすべてのステップを案内してくれます。ボトルネックはソフトウェアではありません。APIキーの管理とTelegramボットの設定であり、これらを一度も行ったことがない場合、それだけで約10分かかります。

一度実行すると、Mac Miniのセットアップはいくつかの特定の点で、あらゆるクラウドオプションを上回ります。BlueBubblesを介したiMessageの統合は機能し、他にこれに匹敵するものはありません。Voice Wakeを使用すると、ネイティブのmacOSアプリを通じてエージェントにハンズフリーで話しかけることができます。これはどのクラウドデプロイメントでも利用できません。ローカルファイルシステムへのアクセスは、エージェントがあなたのマシンから決して離れることのないファイルを扱えることを意味します。

SOUL.mdファイルは、これが他のすべてとは異なると感じ始める点です。これはシステムプロンプトではありません。これは、エージェントが毎日起動時に読み込む永続的なアイデンティティファイルです。1週間それに追記し続けた後、エージェントは私のスケジュール、コミュニケーションスタイル、メール返信の好み、どのカレンダーイベントを任意と見なすかを把握していました。そのコンテキストの蓄積はセッションレベルでは存在しません。それは積み重なっていきます。

厄介な点が一つあります。BlueBubbles経由のiMessage認証は手間がかかり、テストでは2〜3週間ごとに再ログインが必要でした。openclaw doctorコマンドは、丸一日分のメッセージを失う前にこの問題を検知してくれますが、実際にそれを実行する必要があります。

Mac Miniをお持ちか、購入する意思があるなら、これが答えです。機能の上限の高さにおいて、これに匹敵するものはありません。

オプション2：セルフホストVPS (Linux)

最初のメッセージまでの時間： 28分
7日間の稼働率： 100%
月額費用： 約$35 (API) + $6 (VPS)

rootアクセスを必要とするLinuxユーザーや開発者にとって、これはMac MiniのセットアップからVoice WakeとiMessageを除いたものと同等です。インストール方法は同じですが、デスクトップではなくサーバーを維持管理するという点が異なります。

利点は、設計上リモートアクセスが可能であることです。ラップトップが開いているかどうかに関わらず、エージェントにアクセスできます。Tailscale ServeまたはFunnel（公式に推奨されているアプローチ）を使用すると、Gatewayポートを直接公開することなく、これを安全に行うことができます。

欠点は、DevOpsのオーバーヘッドです。午前2時にエージェントが応答しなくなった場合、サーバーにSSHで接続してログを確認することになります。それに抵抗がないのであれば、これは堅実な選択肢です。そうでない場合は、ホスト型オプションに進んでください。

一つ注意すべき点があります。OpenClawがエージェントのシェルアクセスを分離するために推奨しているDockerサンドボックスは、VPSセットアップにおいて顕著な遅延を追加します。チャットの応答は問題ありません。テストでは、ファイル操作やウェブブラウジングを含むタスクは、Mac Miniの同等の環境よりも15～30秒長くかかりました。エージェント自体からのセキュリティ分離を心配しないのであれば、Dockerなしで実行する方が高速です。

上限はMac Miniと同じですが、より柔軟性があり、より多くのメンテナンスが必要です。すでにサーバーを管理しており、新しいことを学びたくない開発者に最適です。

オプション3：TinyClaw

初回メッセージまでの時間： 48秒
7日間の稼働率： 約99.9%
月額費用： $49.99/月（モデル込み）

TinyClaw（tinyclaw.dev）は、AgentPuterが提供するOpenClaw用のクラウドランタイムです。各ユーザーは、共有コンピュートのスライスではなく、独立したコンテナを利用します。実際には、これにより、他の何百人ものユーザーが一度にメッセージを送信しても、エージェントの応答時間が急激に低下することはありません。

オンボーディングは、私たちがテストした中で最も高速でした。Googleサインイン、Telegramの選択、ボットトークンの貼り付けを行い、最初のメッセージが48秒で返ってきました。7日間で、約4分間のメンテナンスウィンドウが1回ありましたが、これは事前に通知されていました。

応答時間は標準的なクエリで平均6〜8秒で、その水準を維持しました。これが、共有コンピュートに対する独立コンテナの実用的な利点です。理想的な条件下でより速いわけではありませんが、理想的でない条件下でも一貫性があります。自宅のMac Miniのインターネット接続は変動しますが、クラウドコンテナの接続は変動しません。

スキルのインストールは安定していました。ClawHubからテストした12のスキルのうち、11は問題なくインストールされました。唯一失敗したのは、OAuthリダイレクト設定が必要なSpotify連携で、これはどのプラットフォームでも手動でのセットアップが必要になります。

音声起動なし、iMessageなし、ローカルファイルシステムなし。これらはTinyClawに特有のものではなく、クラウド展開における構造的な制限です。これらのいずれかが必要な場合、セルフホスティングが唯一の道です。

1つのエージェントを超えて拡張することを考えている場合、AgentPuterの背景が重要になります。同じインフラストラクチャが、1つのアカウントで複数のOpenClawインスタンスをサポートします。異なるコンテキスト用に異なるエージェントを持たせたり、チームメンバー間でアクセスを共有したりできます。それはベーシックプランには含まれていませんが、ニーズが拡大した場合には利用可能です。

オプション4: OpenClaw Cloud

最初のメッセージまでの時間: 2分10秒
7日間の稼働率: 約98.4%
月額費用: 0ドル (無料ティア、月14コンピュート日) または月額9.99ドルのProプラン

OpenClaw Cloud (open.claw.cloud) は、公式に推奨されているホスト版です。主な差別化要因は無料ティアです。Kimi K2.5を搭載し、月に14日間のコンピュート時間が提供されます。注意点として、私たちがテストした時点では、月額9.99ドルのProプランはまだ「近日公開」と表示されていました。そのため、このセクションの一部は、実際に利用可能だった無料ティアに基づいています。

無料ティアは単なるデモではありません。プリインストールされたスキル、Telegram連携、永続メモリ、ブラウザ自動化、そして専用の仮想マシンが利用できます。14日間の無料コンピュート日を使い切ると、VMはパワーオフしますが、データはそのまま保持されます。無料時間が追加されたとき、またはProプランがローンチされたときに、再びパワーオンできます。

Kimi K2.5モデルについては、特筆すべき点があります。メールの要約、返信の下書き、カレンダー管理といったほとんどの実用的なタスクにおいて、テストでは問題なく機能しました。Claude Opus 4.6との差は、複雑で多段階の推論で現れました。「競合他社を3社調査し、価格を比較し、推奨事項を起草する」といったタスクでは、Claudeの方が著しく一貫性のある結果を出しました。そうは言っても、軽量なワークフローを実行するユーザーにとって、Kimi K2.5の価格対性能比は議論の余地がないほど優れています。

ウィザード形式ではなくウェブダッシュボードを通じて設定を行うため、オンボーディングはTinyClawより少し時間がかかります。Telegramの接続には約2分かかりました。スキル管理は完全に公開されており、目的が明確な場合は良いのですが、そうでない場合は分かりにくいかもしれません。

本格的なOpenClaw体験を得るための最も安価な方法です。本格的に導入する前に試してみたい場合に最適な選択肢です。

オプション5：EasyClaw.ai

最初のメッセージまでの時間： 4分
7日間の稼働率： 99.1%
月額費用： 階層に応じて$19～$49

EasyClaw.aiの際立った特徴は、ブラウザベースのデスクトップアクセスです。ブラウザのタブ内で、エージェントのコンテナ環境の完全なビューが得られます。ブラウザ認証が必要なアカウントへのログイン、ツールのインストール、設定ファイルの変更が可能です。これらは、通常のマネージドプラットフォームでは触れさせてもらえない部分です。

私たちはこれを使い、ブラウザフローでの認証が必要なGmail連携を設定しました。これはEasyClawでは簡単ですが、この機能がないプラットフォームでは不可能です。

価格階層は、$5（開発者向け、自身のVPS持ち込み）、$19（マネージド）、$49（上位サポート付きのフルマネージド）となっています。月額$49になると、本当に手間のかからないメンテナンスを望んでいない限り、自己管理のVPSの方が金銭的に理にかなう価格帯に近づきます。

名称に関する注意点が1つあります。「EasyClaw」という名称は、異なる開発者による少なくとも5つの異なる製品で使用されています。easyclaw.ai、easyclaw.app、easyclaw.pro、その他いくつかです。私たちがテストしたのはeasyclaw.aiです。2026年2月上旬、他の類似名のサービスの少なくとも1つが、コミュニティでセキュリティに関する疑問を提起されました。どこかで認証情報を入力する前に、正しいURLにアクセスしていることを確認してください。

オープンソース派生版の状況

ホスティングサービス以外にも、オープンソースの派生版について知っておく価値があります。ただし、これらはより狭い層のオーディエンスを対象としています。

TinyClaw (jlia0版) は、OpenClawのコンセプトを約400行のシェルスクリプトで再実装したものです。Node.jsや完全なフレームワークではなく、Claude Codeとtmuxで構築されています。Discord、WhatsApp、Telegramを横断して複数の独立したエージェントを並列で実行し、競合状態を防ぐファイルベースのメッセージキューを通じて連携します。2026年2月時点でGitHubスターは約2,000、コードベースは午後いっぱいあれば読めるほど小さいです。内部で実際に何が起こっているかを理解したい場合や、制約のある環境にエージェントを組み込む必要がある場合、これが最も直接的な方法です。

TinyClaw (warengonzaga版) は全く別のプロジェクトです。TypeScriptによる書き直しであり、「OpenClawとは完全に独立した製品であり、代替品」であると明確に位置づけています。プラグインアーキテクチャ、自己改善するメモリ、そしてLLMコストを削減するためのスマートなクエリルーティングを重視しています。タスク実行よりも、「パーソナルAIコンパニオン」としての側面に重点を置いています。注目に値しますが、まだ初期段階です。

これらのどちらも、ホスティングサービスと直接競合するものではありません。これらは、根底にあるメカニズムを理解し、変更したい開発者のためのツールです。

実際のところ、どうするか

エージェントを実行したことがない場合：OpenClaw Cloudから始めましょう。無料プランでは14日間、費用をかけたり、ターミナルに触れたりすることなく、これが本当に自分に必要なものかを見極める時間があります。

安定した実行が必要だとわかったら：TinyClawが最もクリーンなアップグレードです。分離されたコンテナ、一貫したパフォーマンス、最速のオンボーディング。将来的に複数のエージェントやチームアクセスが必要になった場合、そのためのインフラはすでに構築されています。

データ主権が重要である場合、またはVoice Wakeが必要な場合、あるいはiMessageが重要な場合：セルフホストしましょう。Mac Miniがハードウェアとして明白な選択肢です — 599ドル、静音、アイドル時3〜4W、macOSをネイティブで実行。ローカルファーストが提供できるものを、クラウドオプションで実現することはできません。

メカニズムを理解したい開発者の方なら：他の何よりも先に、jlia0のTinyClawコードを読んでください。400行のシェルコードは、どんなドキュメントよりも何が起こっているかを詳しく教えてくれます。

率直な評価

「動作する」ことと「役に立つ」ことは同じではありません。私たちがテストしたすべてのオプションは、最初の1時間以内に動作しました。役に立つようになるまでには、より長い時間がかかりました。SOUL.mdにコンテキストを蓄積させ、実際に使用するツールを接続し、デモ用のプロンプトではなく重要なタスクをエージェントに与える必要があったのです。ホスト型オプションの方が、簡単に始められます。セルフホスト型オプションは、開始後にはより多くのことを扱えるようになります。

Skillsエコシステムは、最大の未解決問題です。セキュリティ企業のKoi Securityが2026年2月上旬にClawHubを監査したところ、分析した2,857のSkillsのうち341の悪意のあるSkillsが発見されました。これはカタログの約12%にあたります。そのほとんどは、捕まるまでの1週間で314の汚染されたSkillsを公開した、単一の攻撃者アカウントによるものでした。それ以来、OpenClawはレビュープロセスを追加しましたが、カタログが大きすぎて手動での監査は不可能です。コミュニティのSkillsは、ブラウザ拡張機能と同じように扱ってください。便利で、しばしば優れており、システムアクセスを要求するものをインストールする前には、ソースをざっと見てみる価値があります。

207KものGitHubスターは、何かがうまくいったことを意味します。この特定のものがあなたにとって正しかったかどうかは、ランディングページでわかることではなく、答えるのに1週間かかる問いです。
