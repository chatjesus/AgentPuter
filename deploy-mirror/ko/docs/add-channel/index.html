채널 추가

OpenClaw를 메시징 플랫폼에 연결하세요.
OpenClaw는 15개 이상의 채널을 지원합니다. 하나 또는 여러 개를 추가할 수 있습니다.

1.0 지원 채널

✈️ Telegram

가장 인기 있는 채널입니다. @BotFather로 봇을 만들고 token을 붙여넣으세요.

설정 시간: 약 2분 Telegram 추가하기 →
💬 WebChat

내장 기능. 설정이 필요 없습니다. Dashboard에서 접근하세요.

설정 시간: 0분 (자동) 이미 활성화됨 ✓

1.1+ 버전 출시 예정

📱 WhatsApp 📢 Slack 🎮 Discord 🔐 Signal 📧 Google Chat 🍎 iMessage 💼 Teams 🌐 Matrix

✈️ Telegram 추가하기 — 단계별 안내

1

@BotFather로 봇 생성하기

Telegram 열기 → @BotFather 검색 → /newbot 입력 → 봇 이름 지정 → token 받기

2

Dashboard에 Token 붙여넣기

Dashboard → 채널 → Telegram 추가 → token 붙여넣기 → 연결

123456:ABCDefGhIJKlmNoPQRsTUVwxyz...
3

DM Pairing (OpenClaw 보안 기능)

봇에게 아무 메시지나 보내기 → 페어링 코드 받기 → Dashboard에서 승인하기

⚠️ DM Pairing은 OpenClaw의 보안 기능입니다

알 수 없는 발신자는 페어링 코드를 받게 됩니다. Dashboard 또는 CLI를 통해 승인하세요:
agentputer pairing approve telegram <code>

✓

Telegram 연결 완료!

아무 메시지나 보내 대화를 시작해 보세요. 예: '무엇을 할 수 있니?'

또는 CLI 사용:

$ agentputer channels add telegram

? 봇 token: 123456:ABCDefGhIJKlmNoPQRsTUVwxyz
