添加渠道

将 OpenClaw 连接到你的聊天平台。
OpenClaw 支持 15+ 种渠道，可以添加一个或多个。

1.0 支持的渠道

✈️ Telegram

最受欢迎。通过 @BotFather 创建 Bot，粘贴 Token 即可。

配置时间: ~2 分钟 添加 Telegram →
💬 WebChat

内置功能，无需配置。通过 Dashboard 直接访问。

配置时间: 0 分钟（自动） 已激活 ✓

即将支持 (1.1+)

📱 WhatsApp 📢 Slack 🎮 Discord 🔐 Signal 📧 Google Chat 🍎 iMessage 💼 Teams 🌐 Matrix

✈️ 添加 Telegram — 分步指南

1

通过 @BotFather 创建 Bot

打开 Telegram → 搜索 @BotFather → /newbot → 给 Bot 命名 → 获取 Token

2

在 Dashboard 中粘贴 Token

Dashboard → 渠道 → 添加 Telegram → 粘贴 Token → 连接

123456:ABCDefGhIJKlmNoPQRsTUVwxyz...
3

DM Pairing（OpenClaw 安全机制）

向你的 Bot 发送任意消息 → 收到配对码 → 在 Dashboard 中批准

⚠️ DM Pairing 是 OpenClaw 的安全功能

未知发送者会收到配对码。通过 Dashboard 或 CLI 批准：
agentputer pairing approve telegram <code>

✓

Telegram 已连接！

你的 Bot @my_agent_bot 已与 OpenClaw Agent 关联。
发送任何消息开始聊天。试试："你能做什么？"

或通过 CLI：

$ agentputer channels add telegram

? Bot token: 123456:ABCDefGhIJKlmNoPQRsTUVwxyz

✓ Telegram 渠道已添加到 Pod my-agent
