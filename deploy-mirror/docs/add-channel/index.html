✈️ Add Telegram — Step by Step

1

Create Bot via @BotFather

Open Telegram → search @BotFather → /newbot → name your bot → get token

2

Paste Token in Dashboard

Dashboard → Channels → Add Telegram → paste token → Connect

123456:ABCDefGhIJKlmNoPQRsTUVwxyz...
3

DM Pairing (OpenClaw Security)

Send any message to your bot → receive pairing code → approve in Dashboard

⚠️ DM Pairing is OpenClaw's security feature

Unknown senders receive a pairing code. Approve via Dashboard or CLI:
agentputer pairing approve telegram <code>
