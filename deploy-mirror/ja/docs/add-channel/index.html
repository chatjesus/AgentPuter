チャンネルを追加

OpenClawをメッセージングプラットフォームに接続します。
OpenClawは15以上のチャンネルに対応しています。1つでも複数でも追加できます。

1.0 対応チャンネル

✈️ Telegram

最も人気。@BotFatherでボットを作成し、tokenを貼り付けます。

設定時間: 約2分 Telegramを追加 →
💬 WebChat

内蔵機能。設定不要。Dashboardからアクセスできます。

設定時間: 0分 (自動) 有効化済み ✓

1.1+で登場予定

📱 WhatsApp 📢 Slack 🎮 Discord 🔐 Signal 📧 Google Chat 🍎 iMessage 💼 Teams 🌐 Matrix

✈️ Telegramを追加 — ステップ・バイ・ステップ

1

@BotFatherでボットを作成

Telegramを開く → @BotFatherを検索 → /newbot → ボットに名前を付ける → tokenを取得

2

DashboardでTokenを貼り付け

Dashboard → チャンネル → Telegramを追加 → tokenを貼り付け → 接続

123456:ABCDefGhIJKlmNoPQRsTUVwxyz...
3

DM Pairing (OpenClawセキュリティ)

ボットに何かメッセージを送信 → ペアリングコードを受信 → Dashboardで承認

⚠️ DM PairingはOpenClawのセキュリティ機能です

不明な送信者はペアリングコードを受け取ります。DashboardまたはCLIで承認してください:
agentputer pairing approve telegram <code>
