OpenClaw 突破 207,000 GitHub Stars 的同時，一個平行生態也在悄悄爆發：AI Agent Skills 市場。
這些平台是開發者發布和發現 Skills 的地方——也就是那些 SKILL.md 檔案，告訴 OpenClaw 怎麼管理你的郵件、控制日曆、監控 GitHub 倉庫，甚至讓 Agent 自我進化。

原因是 Anthropic。這個站是 Anthropic 定義的"Agent Skills"開放格式的官方主頁——Claude Code、Cursor、OpenAI Codex 和 OpenClaw 共用的 SKILL.md 標準。靠著 Anthropic 的影響力，它天然獲得了品牌認知和直接流量。
參與度指標印證了這一點：平均 1.8 分鐘會話時長，62.4% 跳出率，2.2 頁/次。用戶來了，掃一眼技能列表或文檔頁就離開。沒有留下來的理由。

一段話說清競爭格局：SkillsMP 有流量但沒有 OpenClaw 深度。agentskills.io 有品牌但內容不耐用。ClawHub 有對的用戶但沒有觸達能力。而整個可計量市場——以 SkillsMP 11 月的流量為基準
**機會二：中文 OpenClaw 內容幾乎不存在。** SkillsMP 靠通用 AI 內容統治中文流量。但專門針對 OpenClaw 的中文內容——如何在國內 VPS 部署、哪些 Skills 支援 DeepSeek / Kimi 等國產模型、如何
**如果你只是想找好的 Skills 用：** 不要只靠 ClawHub 的瀏覽介面。官方 Registry 有真貨——3,286 個 Skills，有真實下載數據和安全評分——但發現體驗很薄。在專屬內容平臺成熟之前，最好的資源是 [
