CINQ RÔLES, UNE PLATEFORME

AgentPuter n'est pas qu'une simple liste de fonctionnalités.
Il joue cinq rôles critiques dans votre flux de travail IA.

[🔒]

Privacy Proxy

// Vos données ne quittent jamais votre contrôle

Vous ne colleriez pas vos identifiants bancaires dans ChatGPT. AgentPuter agit comme un pare-feu entre vous et les LLM — il nettoie les données, gère les autorisations et garantit que la propriété des données reste entre vos mains.

agentputer — privacy proxy

$ agentputer privacy status

 

Flux de données : Utilisateur → AgentPuter → [NETTOYÉ] → LLM

Identifiants : chiffrés au repos (AES-256)

Clés API : gérées, jamais exposées aux modèles

Détection PII : active, masquage auto activé

✓ Vos données restent les vôtres

[🧠]

Context Manager

// Une mémoire qui n'oublie jamais

Les LLM sont amnésiques. AgentPuter donne à votre agent une mémoire à long terme. Il convertit les flux de travail, les préférences et l'historique des fichiers en contexte structuré — économisant des tokens tout en améliorant la précision.

agentputer — context manager

$ agentputer context show

 

Mémoire long terme: 847 entrées

Préférences: 23 règles chargées

Historique: 156 fichiers suivis

Économie tokens: ~62% (contexte intelligent)

Synchro: il y a 2 min

✓ Reprend là où vous vous êtes arrêté

[🔌]

Unified Interface

// Une seule API pour tout ce dont votre agent a besoin

Chaque capacité — documents, e-mails, web, code — est encapsulée en tant que Tool standardisé. Les agents appellent les capacités aussi naturellement qu'un humain utilise une souris, sans avoir à apprendre chaque API.

agentputer — unified interface

$ agentputer tools list

 

├── documents (lire, écrire, convertir)

├── email (envoyer, lire, chercher)

├── web (naviguer, scraper, API)

├── calendar (événements, rappels)

├── code (exécuter, tester, deploy)

├── files (CRUD, organiser)

└── custom (Marketplace de Skills)

✓ 7 tools principaux + Skills illimités

[💾]

Persistent Workspace

// Le propre bureau de votre agent

L'agent dispose de son propre système de fichiers, dépôt de code et notes de recherche. Le travail inachevé est sauvegardé. La session suivante reprend exactement là où la précédente s'est arrêtée.

$ agentputer workspace status

├── projects/ (3 actifs)

├── research/ (12 notes)

├── drafts/ (5 en cours)

└── exports/ (8 terminés)

 

Stockage: 2.1 Go / 40 Go

✓ Le foyer persistant de votre agent

[📋]

Accountability Log

// Chaque action, enregistrée et vérifiable

Voyez exactement ce que votre agent a fait, quand et pourquoi. Les chaînes de décision complètes sont journalisées. Les actions sensibles sont automatiquement mises en pause pour confirmation humaine. La confiance par la transparence.

agentputer — accountability log

$ agentputer logs --last 5

 

[14:23:01] [agent] Reçu : 'compiler le rapport de ventes'

[14:23:02] [agent] Plan : récupérer données → analyser → formater

[14:23:05] [tool] Interrogé la base de données : sales_q4_2025

[14:23:08] [agent] Brouillon de rapport généré

[14:23:09] [⚠ CONFIRMER] Envoyer l'e-mail au manager ?

[14:23:15] [humain] Approuvé ✓

✓ Intervention humaine pour les opérations sensibles

CAS D'UTILISATION

Que peut réellement faire votre agent ?

📊

Travail de bureau

"Compile les données de ventes de la semaine dernière, rédige un rapport et envoie-le par e-mail à mon manager." L'agent récupère les données, les analyse, les met en forme et les envoie — vous n'avez qu'à vérifier.

🔬

Recherche

"Fais des recherches sur les tendances du marché des véhicules électriques pour 2025." Il cherche, lit, extrait les points clés et produit un carnet de notes — sauvegardé pour le suivi.

💻

Développement

"Crée une page d'accueil pour notre produit." Propre environnement de dev. Écrit du code, exécute des tests, corrige les bugs, déploie — vous demande de l'aide en cas de blocage.

🎨

Création

"Conçois une campagne pour les réseaux sociaux pour le T1." Propre canevas et ressources. Génère des brouillons, itère, sauvegarde les versions. Vous dirigez.
